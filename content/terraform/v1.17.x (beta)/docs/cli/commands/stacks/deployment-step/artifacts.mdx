# `terraform stacks deployment-step artifacts` reference

Use the `terraform stacks deployment-step artifacts` command to retrieve raw
artifact data for a deployment step.

## Usage

```shell-session
$ terraform stacks <global-stacks-flags> deployment-step artifacts -deployment-step-id=<step-id> -artifact-name=<artifact-name>
```

## Description

The `terraform stacks deployment-step artifacts` command retrieves an artifact
for a deployment step and writes its raw content to standard output without
parsing or filtering it. Use artifacts to troubleshoot scenarios where
diagnostics and normal command output do not provide enough context.

Plan steps can provide `plan-description` and `plan-debug-log` artifacts. Apply
steps can provide `apply-description` and `apply-debug-log` artifacts. Run the
`terraform stacks deployment-step show` command to list the artifacts available
for a step.

## Options

- `-artifact-name`: The artifact to retrieve.
    - Required.
    - String.
    - Valid values: `apply-debug-log`, `apply-description`,
      `plan-debug-log`, and `plan-description`.
- `-deployment-step-id`: The ID of the deployment step.
    - Required.
    - String.

## Examples

The following command retrieves a plan description:

```shell-session
$ terraform stacks deployment-step artifacts \
  -deployment-step-id=sds-abc123 \
  -artifact-name=plan-description
```

The following command writes a plan debug log to a file:

```shell-session
$ terraform stacks deployment-step artifacts \
  -deployment-step-id=sds-abc123 \
  -artifact-name=plan-debug-log > plan-debug.log
```
