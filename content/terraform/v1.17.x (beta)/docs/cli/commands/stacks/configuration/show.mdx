# `terraform stacks configuration show` reference

Use the `terraform stacks configuration show` command to display details about a
Stack configuration and its deployment groups.

## Usage

```shell-session
$ terraform stacks <global-stacks-flags> configuration show <options>
```

## Description

The `terraform stacks configuration show` command displays a configuration's ID,
sequence number, status, and deployment groups. For configurations created from a
version control system (VCS), the output also includes the branch, commit SHA, and
sender username.

Specify a configuration with `-configuration-id`, or specify
`-organization-name`, `-project-name`, and `-stack-name` to show the latest
configuration for a Stack.

When a configuration fails, the human-readable output reports available
preparation diagnostics and failed or abandoned deployment groups. It also
provides commands for inspecting the diagnostics and deployment runs.

## Options

- `-configuration-id`: The ID of the configuration to show.
    - Required unless you specify `-organization-name`, `-project-name`, and
      `-stack-name`.
    - String.
    - Takes precedence over name-based targeting.
- `-json`: Output results in JSON format instead of the default human-readable
  format.
    - Optional.
    - Boolean.
    - Default: `false`.
- `-organization-name`: The name of the organization that contains the Stack.
    - Required for name-based targeting.
    - String.
    - Overrides the `TF_STACKS_ORGANIZATION_NAME` environment variable.
- `-project-name`: The name of the project that contains the Stack.
    - Required for name-based targeting.
    - String.
    - Overrides the `TF_STACKS_PROJECT_NAME` environment variable.
- `-stack-name`: The name of the Stack.
    - Required for name-based targeting.
    - String.
    - Overrides the `TF_STACKS_STACK_NAME` environment variable.

## Examples

The following command shows a configuration by ID:

```shell-session
$ terraform stacks configuration show -configuration-id=stc-abc123
```

The following command shows the latest configuration for a Stack:

```shell-session
$ terraform stacks configuration show \
  -organization-name=my-org \
  -project-name=my-project \
  -stack-name=my-stack
```

The following command shows a configuration in JSON format:

```shell-session
$ terraform stacks configuration show -configuration-id=stc-abc123 -json
```
