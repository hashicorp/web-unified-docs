# `terraform stacks deployment-step show` reference

Use the `terraform stacks deployment-step show` command to display details about
a deployment step.

## Usage

```shell-session
$ terraform stacks <global-stacks-flags> deployment-step show -deployment-step-id=<step-id> <options>
```

## Description

The `terraform stacks deployment-step show` command displays a deployment
step's ID, status, and operation type. For plan and apply steps, the output also
lists the artifacts that are available to retrieve.

## Options

- `-deployment-step-id`: The ID of the deployment step to show.
    - Required.
    - String.
- `-json`: Output results in JSON format instead of the default human-readable
  format.
    - Optional.
    - Boolean.
    - Default: `false`.

## Examples

The following command shows a deployment step:

```shell-session
$ terraform stacks deployment-step show -deployment-step-id=sds-abc123
```

The following command shows a deployment step in JSON format:

```shell-session
$ terraform stacks deployment-step show -deployment-step-id=sds-abc123 -json
```
