# `terraform stacks deployment-step` reference

Use the `terraform stacks deployment-step` commands to inspect deployment steps
and retrieve their artifacts.

## Usage

```shell-session
$ terraform stacks <global-stacks-flags> deployment-step <subcommand>
```

## Description

The `terraform stacks deployment-step` command group provides subcommands for
viewing a deployment step's status, operation type, and available artifacts. You
can also retrieve the raw content of an artifact for troubleshooting.

## Subcommands

- [`artifacts`](/terraform/cli/commands/stacks/deployment-step/artifacts):
  Retrieve raw artifact data for a deployment step.
- [`show`](/terraform/cli/commands/stacks/deployment-step/show): Show details
  about a deployment step.
