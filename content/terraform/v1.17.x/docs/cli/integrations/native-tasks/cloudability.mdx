# Cloudability native task CLI output

<Note>

The Cloudability native task is currently in public beta, and is available in Terraform Enterprise, HCP Terraform **Standard**, and HCP Terraform **Premium** editions. Refer to [HCP Terraform pricing](https://www.hashicorp.com/products/terraform/pricing) for details.

</Note>

The Cloudability native task allows you to integrate Cloudability into your Terraform runs to estimate costs, enforce policies, and suggest infrastructure optimizations between the plan and apply phases.

To set up and configure the integration (including organization requirements, FQDN network configurations, and usage estimates), refer to the [Set up the Cloudability native task integration guide](/terraform/cloud-docs/integrations/native-tasks/cloudability).

When you run a plan or apply in the Terraform CLI, the Cloudability native task streams a summary of these results directly to your console. Each line of the summary is prefixed by a vertical bar (`│`).

The CLI summary displays the following sections:

- **Cost Estimation**: Projected monthly cost changes, total cost differences, and the count of estimated resources.
- **Governance Summary**: The overall status of the run checks (such as `PASSED` or `FAILED`).
- **Policies Summary**: The count of failed policies and descriptions of policy violations, including rule name, category, and specific resource attribute or tag requirements.
- **Resource Recommendations**: Optimization recommendations, suggested configuration updates, and estimated monthly savings.

## CLI output examples

The following examples demonstrate the CLI output format for different states of the Cloudability native task.

### Successful run with cost estimates and recommendations

This example shows a run that passed governance, displaying cost increases, policy details, and a configuration recommendation:

```text
│ Cloudability — Passed
│ Monthly cost will increase to: $496.40/month
│ Total monthly cost diff: +$496.40/mo
│ Resources estimated: 2/8
│ Governance Summary: PASSED
│ Policies Summary: 2/2 policies failed
│ - Allowed Compute Sizes [vendor, advisory]
│   'Instance Type' with value "c5.4xlarge" was given for resource 'EC2 - Compute Instance' with address aws_instance.oversized_workers[0].
│   This violates the rule: 'Instance Type' must IN "a1.medium".
│ - Tag Governance: Cost Center [tagging, advisory]
│   'cost-center' tag is missing or invalid for resource 'DynamoDB Table' with address aws_dynamodb_table.web_data.
│   'cost-center' tag is missing or invalid for resource 'EC2 - Compute Instance' with address aws_instance.oversized_workers[0].
│   'cost-center' tag is missing or invalid for resource 'aws_internet_gateway' with address aws_internet_gateway.web_igw.
│   'cost-center' tag is missing or invalid for resource 'aws_route_table' with address aws_route_table.web_public_rt.
│   'cost-center' tag is missing or invalid for resource 'aws_security_group' with address aws_security_group.web_sg.
│   'cost-center' tag is missing or invalid for resource 'aws_subnet' with address aws_subnet.web_public.
│   'cost-center' tag is missing or invalid for resource 'aws_vpc' with address aws_vpc.web_vpc.
│ Resource Recommendations: 1
│ Change configuration of EC2 - Compute Instance from c5.4xlarge to a1.4xlarge.
│ Details: https://tfcdev-8689acac.ngrok.app/app/hashicorp/ws-3/runs/run-GhA33nX3BcGnWKdN
```
