# Cloudability native task CLI output

<Note>

The Cloudability native task is currently available in public beta for Terraform Enterprise and HCP Terraform Standard and Premium editions.

</Note>

The Cloudability native task integrates Cloudability into Terraform runs to provide cost estimates, policy validation, and infrastructure optimization recommendations (between the plan and apply phases).

For setup instructions, including organization requirements, network configuration, and usage estimates, refer to the [Cloudability native task integration guide](/terraform/cloud-docs/integrations/native-tasks/cloudability).

During the post-plan stage, Cloudability streams a summary of its results directly into the Terraform CLI output. The CLI summary can include:

- Overall task status.
- Estimated monthly cost changes, total cost impact, and the number of resources included in the estimate.
- Governance results, including the overall governance status.
- Policy evaluation results, including failed policies and details about policy violations.
- Resource optimization recommendations and suggested configuration updates.
