# Upgrade Consul to v2.1.x

This page describes version-specific considerations, migrations, and validations required when upgrading to Consul 2.1.x from earlier releases.

## Overview

Consul 2.1.x is a modification release that introduces configurable TLS key-exchange groups for service mesh and agent connections, new API gateway features, and changes to proxy certificate delivery. For general upgrade procedures (rolling upgrade strategy, server/client upgrade steps, etc.), refer to the [General Upgrade Process](/consul/docs/upgrade/instructions/general).

This guide focuses on **version-specific migration requirements**, **pre-upgrade validations**, **post-upgrade behavior changes**, and **feature-specific procedures**.

## Upgrade paths

Consul 2.1.x can be reached from two different release branches:

- **From Consul 2.0.x** → 2.1.x (recommended, shorter path)
- **From Consul 1.21.x** → 2.1.x (legacy path, requires intermediate step)

Select your current version below to see version-specific guidance.

### API gateway configuration options requiring full 2.1.x upgrade

The following API gateway options are not recognized by Consul 2.0 servers and will be rejected, ignored, or applied incorrectly. Complete the full 2.1.x upgrade before using these options:

- `Listeners[].Protocol` = `http2` or `grpc`
- `Rules[].Matches[].Headers[].Invert`
- `Defaults.PassiveHealthCheck` and `Limits.PassiveHealthCheck`

### API gateway TLS behavior change

#### TLS.Enabled now applies to all listeners

In Consul 2.0, setting `TLS.Enabled = true` without listener-specific certificates or TLS parameters has no effect. In Consul 2.1, all listeners use TLS (HTTPS) termination.

**Pre-upgrade audit required:**

1. Find all api-gateway entries with `TLS.Enabled = true`:
   ```shell-session
   $ consul config list -kind api-gateway | while read -r gateway; do
       consul config read -kind api-gateway -name "$gateway" \
         | jq -r 'select(.TLS.Enabled == true) | .Name'
     done
   ```

2. For each gateway found, choose one of the following before upgrading:
