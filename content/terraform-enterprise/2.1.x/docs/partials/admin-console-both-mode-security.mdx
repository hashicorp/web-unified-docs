~> **Security Note:** When `TFE_ADMIN_CONSOLE_ACCESS_MODE` is set to `both`, the admin console becomes accessible on port `:443`, which is already open for standard TFE traffic. This bypasses network-level blocking of the dedicated admin console port (`:8443`). To restrict access to the admin console when using `both` mode, implement path-level IP allow-listing at your reverse proxy or load balancer (e.g., Nginx, HAProxy, AWS ALB, or Kubernetes Ingress) to control access to the `/platform/admin` path.
