| Mode | Description | Default |
|------|-------------|---------|
| `port` | Admin console UI and System API are accessible only via the dedicated admin port (e.g., `:8443`) under `/api/v1` | ✅ Yes |
| `path` | Admin console UI and System API are accessible only via standard HTTPS path (`/platform/admin` and `/platform/admin/api/v1`) | No |
| `both` | Admin console UI and System API are accessible via both the dedicated admin port and standard HTTPS path | No |
| `disabled` | Admin console and System API are disabled and inaccessible | No |
| (unset) | Falls back to the value of `TFE_ADMIN_CONSOLE_DISABLED`. If `TFE_ADMIN_CONSOLE_DISABLED` is `true`, the console UI is disabled but the System API remains available on the dedicated admin port; otherwise, behavior is equivalent to `port` | No |

By default, you can only access the admin console and System API through the dedicated port. This provides network-level isolation, as you can block the dedicated port at the firewall or load balancer level to restrict access to authorized networks or IP addresses.
