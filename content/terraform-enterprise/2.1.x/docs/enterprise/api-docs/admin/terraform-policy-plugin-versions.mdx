# Admin Terraform policy plugin versions API


The `/admin/tfpolicy-versions` API endpoint lets site administrators manage which versions of Terraform policy are available to Terraform Enterprise users.

## List all Terraform policy plugin versions

`GET /api/v2/admin/tfpolicy-versions`

This endpoint lists all known versions of the Terraform policy plugin.

| Status  | Response                                             | Reason                                 |
| ------- | ---------------------------------------------------- | -------------------------------------- |
| [200][] | [JSON API document][] (`type: "tfpolicy-versions"`)  | Successfully lists Terraform policy plugin versions.  |
| [404][] | [JSON API error object][]                            | Client is not an administrator.        |

### Query Parameters

This endpoint supports pagination [with standard URL query parameters](/terraform/enterprise/api-docs#query-parameters). Remember to percent-encode `[` as `%5B` and `]` as `%5D` if your tooling doesn't automatically encode URLs.

| Parameter         | Description                                                                                                                                                                                                                  |
| ----------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `filter[version]` | **Optional.** Specifies a Terraform policy plugin version to filter for as a query string. Terraform Enterprise matches on the exact version. This option takes precedence over search queries.  |
| `search[version]` | **Optional.** Specifies a Terraform policy plugin version to search for as a query string. Terraform Enterprise matches on the exact version.                                        |
| `sort`            | **Optional.** Allows sorting by version. The only valid value is `"version"`. Prepending a hyphen to the sort parameter reverses the order, for example `"-version"`. If omitted, the default sort order is descending.           |
| `page[number]`    | **Optional.** If omitted, the endpoint returns the first page.                                                                                                                                                           |
| `page[size]`      | **Optional.** If omitted, the endpoint returns 20 Terraform policy plugin versions per page.                                                                                                                                           |

### Sample Request

```shell
curl \
  --header "Authorization: Bearer $TOKEN" \
  --header "Content-Type: application/vnd.api+json" \
  "https://tfe.example.com/api/v2/admin/tfpolicy-versions"
```

## Create a Terraform policy plugin version

`POST /api/v2/admin/tfpolicy-versions`

| Status  | Response                                             | Reason                                         |
| ------- | ---------------------------------------------------- | ---------------------------------------------- |
| [201][] | [JSON API document][] (`type: "tfpolicy-versions"`)  | The Terraform policy plugin version was successfully created. |
| [404][] | [JSON API error object][]                            | The client is not an administrator.            |
| [422][] | [JSON API error object][]                            | Validation errors.                             |

### Request Body

When sending a `POST` request, you must provide a JSON object with the following properties as the request payload.

Properties without a default value are required.

We recommend setting the URL and SHA-256 checksum of a Terraform policy plugin binary in the `archs[n].url` and `archs[n].sha` fields.

| Key path                            | Type   | Default | Description                                                                                                                                                           |
| ----------------------------------- | ------ | ------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `data.type`                         | string |         | Must be `"tfpolicy-versions"`.                                                                                                                                        |
| `data.attributes.version`           | string |         | A semantic version string in N.N.N or N.N.N-bundleName format (`"0.11.0"` or `"0.12.20-beta1"`).                                                                      |
| `data.attributes.url`               | string |         | The URL where you can download the Linux amd64 binary of this version. We recommend using the `archs[n].url` field instead.               |
| `data.attributes.sha`               | string |         | The SHA-256 checksum of the Linux amd64 Terraform policy plugin binary. We recommend using the `archs[n].sha` field instead.                             |
| `data.attributes.deprecated`        | bool   | `false` | Whether or not this version of Terraform policy plugin is deprecated.                                                                                                                |
| `data.attributes.deprecated-reason` | string | `null`  | Additional context about why a version of Terraform policy plugin is deprecated. Field is `null` unless the `data.attributes.deprecated` attribute is `true`.                                                         |
| `data.attributes.official`          | bool   | `false` | Whether or not this is an official release of Terraform policy plugin.                                                                                                               |
| `data.attributes.enabled`           | bool   | `true`  | Whether or not this version of Terraform policy plugin is enabled for use in HCP Terraform.                                                                                          |
| `data.attributes.beta`              | bool   | `false` | Whether or not this version of Terraform policy plugin is a beta pre-release.                                                                                                        |
| `data.attributes.archs`             | array  |         | An array of architecture objects.                                                                                                                                     |
| `data.attributes.archs[n].url`      | string |         | The URL where you can download the 64-bit Linux binary of this version. We recommend using this field to set the URL instead of the `url` field.                      |
| `data.attributes.archs[n].sha`      | string |         | The SHA-256 checksum of the Terraform policy plugin binary. We recommend using this field to set the checksum instead of the `sha` field.                                            |
| `data.attributes.archs[n].os`       | string |`"linux"`| Terraform policy plugin version operating system.                                                                                                                                    |
| `data.attributes.archs[n].arch`     | string |`"amd64"`| Terraform policy plugin version architecture.                                                                                                                                        |

## Delete a Terraform policy plugin version

`DELETE /api/v2/admin/tfpolicy-versions/:id`

This endpoint removes a Terraform policy plugin version from HCP Terraform. You cannot remove officially labeled Terraform policy plugin versions or any version used by a workspace.

| Parameter | Description                               |
| --------- | ----------------------------------------- |
| `:id`     | The ID of the Terraform policy plugin version to delete. |

| Status  | Response                  | Reason                                                                                                               |
| ------- | ------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| [204][] | Empty response            | The Terraform policy plugin version was successfully deleted.                                                                       |
| [404][] | [JSON API error object][] | The request could not find a matching Terraform policy plugin version with the specified ID, or the client is not an administrator. |
| [422][] | [JSON API error object][] | The request could not remove the Terraform policy plugin version because it is an official version or a workspace uses it.          |

### Sample Request

```shell
curl \
  --header "Authorization: Bearer $TOKEN" \
  --header "Content-Type: application/vnd.api+json" \
  --request DELETE \
  https://app.terraform.io/api/v2/admin/tfpolicy-versions/tool-L4oe7rNwn7J4E5Yr
```
