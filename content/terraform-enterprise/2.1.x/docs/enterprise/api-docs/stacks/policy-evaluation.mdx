# Stack policy evaluations API reference

Terraform policy evaluations run as part of a stacks plan. When Terraform Enterprise executes a stack plan step and the organization is entitled to policy enforcement, Terraform Enterprise creates a Terraform policy evaluation and one policy set outcome per attached policy set, all within the same job that runs the plan.

This set of APIs provides endpoints to show a Terraform policy evaluation and list its associated policy set outcomes

## Show a stack policy evaluation

`GET /stack-policy-evaluations/:stack_policy_evaluation_id`

| Parameter                      | Description                         |
| ------------------------------ | ----------------------------------- |
| `:stack_policy_evaluation_id`  | The external ID of the policy evaluation to retrieve. |

| Status  | Response                  | Reason                                                                   |
| ------- | ------------------------- | ------------------------------------------------------------------------ |
| [200][] | [JSON API document][]     | Success                                                                  |
| [401][] | [JSON API error object][] | User is not authorized to read this policy evaluation                    |
| [404][] | [JSON API error object][] | Policy evaluation not found                                              |

### Query Parameters

| Parameter                       | Description                                                                                                           |
| ------------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| `include`                       | **Optional.** Comma-separated list of related resources to sideload. Supported value: `stack_policy_set_outcomes`.   |

### Sample Request

```shell
curl \
  --header "Authorization: Bearer $TOKEN" \
  --header "Content-Type: application/vnd.api+json" \
  --request GET \
  https://tfe.example.com/api/v2/stack-policy-evaluations/speval-HjkrEHMbYQrwJQHh
```

### Attribute reference

| Attribute                          | Type     | Description                                                                                                  |
| ---------------------------------- | -------- | ------------------------------------------------------------------------------------------------------------ |
| `status`                           | string   | Current evaluation status. One of `pending`, `passed`, `failed`, `errored`, or `unknown`.                  |
| `policy-attachable-id`             | string   | External ID of the stack plan this evaluation is attached to.                    |
| `policy-attachable-type`           | string   | The type of resource the evaluation is attached to. Currently always `"plan"`.                              |
| `result-count`                     | object   | Aggregate policy result counts. See [result-count object](#result-count-object) below.                      |
| `error`                            | object \| null | Structured error details when the evaluation status is `errored`. See [error object](#error-object) below. `null` when no error occurred. |
| `created-at`                       | string   | ISO 8601 timestamp when the evaluation was created.                                                          |
| `updated-at`                       | string   | ISO 8601 timestamp when the evaluation was last updated.                                                     |

#### result-count object

| Key                             | Type    | Description                                                           |
| ------------------------------- | ------- | --------------------------------------------------------------------- |
| `advisory-failed`               | integer | Number of advisory policies that failed.                              |
| `mandatory-failed`              | integer | Number of hard mandatory policies that failed.                      |
| `mandatory-overridable-failed`  | integer | Number of overridable mandatory policies that failed.|
| `passed`                        | integer | Total number of policies that passed.                                 |
| `errored`                       | integer | Number of policies that encountered an error during evaluation.       |
| `unknown`                       | integer | Number of policies whose result could not be determined.              |

#### error object

Terraform Enterprise sets the `error` attribute when the evaluation status is `errored` and the failure is the result of a compatibility or configuration problem detected before the agent could run policies. It is `null` in all other cases.

| Key       | Type   | Description                                                                 |
| --------- | ------ | --------------------------------------------------------------------------- |
| `type`    | string | Machine-readable error category. Possible values are `incompatible_agent_version`, `incompatible_terraform_version_error`, `tool_version_error`, `missing_stack_configuration`. |
| `summary` | string | Short human-readable summary of the error.                                  |
| `detail`  | string | Detailed description of the error and how to resolve it.                    |

## List stack policy set outcomes

`GET /stack-policy-evaluations/:stack_policy_evaluation_id/stack-policy-set-outcomes`

| Parameter                     | Description                                          |
| ----------------------------- | ---------------------------------------------------- |
| `:stack_policy_evaluation_id` | The external ID of the policy evaluation to list outcomes for. |

This endpoint lists all policy set outcomes associated with the given stack policy evaluation. Each outcome corresponds to a single policy set that was evaluated.

| Status  | Response                  | Reason                           |
| ------- | ------------------------- | -------------------------------- |
| [200][] | [JSON API document][]     | Success                          |
| [401][] | [JSON API error object][] | User is not authorized           |
| [404][] | [JSON API error object][] | Policy evaluation not found      |

### Query Parameters

This endpoint supports pagination [with standard URL query parameters](/terraform/enterprise/api-docs#query-parameters). Remember to percent-encode `[` as `%5B` and `]` as `%5D` if your tooling does not automatically encode URLs.

| Parameter                       | Description                                                                                                                                                          |
| ------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `page[number]`                  | **Optional.** If omitted, the endpoint returns the first page.                                                                                                       |
| `page[size]`                    | **Optional.** If omitted, the endpoint returns 20 outcomes per page.                                                                                                 |
| `filter[n][status]`             | **Optional.** Filters outcomes by policy result status. Must be one of `passed`, `failed`, or `errored`. Can be combined with `filter[n][enforcement_level]`.        |
| `filter[n][enforcement_level]`  | **Optional.** Filters outcomes by policy enforcement level. Must be one of `advisory`, `mandatory`, or `mandatory_overridable`. Only meaningful alongside a non-errored `status` filter. |

You can use indexed `filter[n]` parameters to combine multiple status and enforcement-level combinations. The endpoint returns all policy set outcomes that contain at least one individual policy result matching any of the specified filter criteria.

### Sample Requests
The following sample requests demonstrate common use cases.
#### All policy set outcomes

```shell
curl \
  --header "Authorization: Bearer $TOKEN" \
  --header "Content-Type: application/vnd.api+json" \
  --request GET \
  https://tfe.example.com/api/v2/stack-policy-evaluations/speval-HjkrEHMbYQrwJQHh/stack-policy-set-outcomes
```

#### Filter by failed mandatory and errored outcomes

```shell
curl \
  --header "Authorization: Bearer $TOKEN" \
  --header "Content-Type: application/vnd.api+json" \
  --request GET \
  "https://tfe.example.com/api/v2/stack-policy-evaluations/speval-HjkrEHMbYQrwJQHh/stack-policy-set-outcomes?filter[0][status]=failed&filter[0][enforcement_level]=mandatory&filter[1][status]=errored"
```

### Attribute reference

| Attribute                         | Type          | Description                                                                                             |
| --------------------------------- | ------------- | ------------------------------------------------------------------------------------------------------- |
| `policy-set-name`                 | string        | The name of the policy set evaluated.                                                                   |
| `policy-set-description`          | string \| null | The description of the policy set, or `null` if no description was set.                                |
| `result-count`                    | object        | Per-enforcement-level policy result counts for this policy set. See [result-count object](#result-count-object). |
| `policy-set-result-url`           | string \| null | A pre-signed URL where you can download the raw JSON result file produced by the agent for this policy set. The URL is active for 30 minutes. This attribute is `null` when Terraform Enterprise has not stored a result. |
