# Policy enforcement in workspaces

This section provides an overview of how Terraform Enterprise enforces policies for configurations in workspaces.

For general information about policies, policy sets, and policy frameworks, refer to the [Policy enforcement overview](/terraform/enterprise/policy-enforcement).

## Workspace-specific features

The following features are specific to viewing and managing policy enforcement in workspaces:

- View and override policy enforcement results in the workspace UI. Refer to [View policy results](/terraform/enterprise/workspaces/policy-enforcement/view-results) for more information.
- Access detailed JSON output for Sentinel policies. Refer to [View Sentinel JSON results](/terraform/enterprise/workspaces/policy-enforcement/view-results/json) for more information.

## General policy documentation

For information about creating and managing policies that apply to both workspaces and Stacks, refer to the following topics:

- [Define policies](/terraform/enterprise/policy-enforcement/define-policies): Write custom policies using Terraform policy, Sentinel, or OPA
- [Create and manage policy sets](/terraform/enterprise/policy-enforcement/manage-policy-sets): Organize policies and configure their scope
- [Configure policy set connections](/terraform/enterprise/policy-enforcement/manage-policy-sets/configure): Set up VCS, managed, or automated policy set workflows
- [Test policies](/terraform/enterprise/policy-enforcement/test): Test your policies before deploying them
- [Pre-written policy library](/terraform/enterprise/policy-enforcement/prewritten-library): Use HashiCorp-maintained policies
- [Sentinel import reference](/terraform/enterprise/policy-enforcement/import-reference): Reference for Sentinel imports

## Policy enforcement for Stacks

For information about using policies with Stacks, refer to [Policy enforcement for Stacks](/terraform/enterprise/stacks/policy-enforcement).
