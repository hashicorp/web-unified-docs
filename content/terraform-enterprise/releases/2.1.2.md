#### Possible Customer Impacting Changes

These PRs included a changelog line the PR body. This changelog line has been used as the message below.

1. Explorer runtime reports now work for workspaces that use dynamic provider credentials. -- **@hc-tfe-release-bot** [atlas#32883](https://github.com/hashicorp/atlas/pull/32883)
1. Fixed an issue where Admin API responses returned links (`self`, pagination, and `download`) without the `/platform/admin` prefix when the Admin API was accessed through the standard HTTPS path (`TFE_ADMIN_CONSOLE_ACCESS_MODE` set to `path` or `both`), causing those links to return 404. Links returned to clients using the dedicated Admin API port (`:8443/api/...`) are unchanged. -- **@hc-tfe-release-bot** [terraform-enterprise#5880](https://github.com/hashicorp/terraform-enterprise/pull/5880)
1. The archivist startup check now waits for its temporary archivist process to become ready before exercising the archivist API. This prevents spurious `connection refused` startup failures on hosts where archivist takes more than a second to start, such as the first boot of a new cloud instance. -- **@hc-tfe-release-bot** [terraform-enterprise#5868](https://github.com/hashicorp/terraform-enterprise/pull/5868)
1. Terraform Enterprise no longer starts the legacy `slug-ingress` service by default. To use it for VCS ingress, set `TFE_VCS_INGRESS_SLUG_INGRESS_FALLBACK=true` and restart Terraform Enterprise. -- **@hc-tfe-release-bot** [terraform-enterprise#5997](https://github.com/hashicorp/terraform-enterprise/pull/5997)
1. Fixed an issue where support bundle uploads ignored `TFE_OBJECT_STORAGE_S3_ENABLE_MD5_VALIDATION` on S3-compatible object stores. -- **@hc-tfe-release-bot** [terraform-enterprise#6024](https://github.com/hashicorp/terraform-enterprise/pull/6024)
1. Large agent policy evaluation with trace level agent logging now does not cause stuck runs.  Previously, users configuring `TFC_AGENT_LOG_LEVEL=trace` on their custom run pipeline image would have policy run containers to not properly exit, overtime this would lead to no agent runs being processed on the TFE instance, which was fixed by restarting the instance.  Large log outputs in the agent logs are now properly buffered -- **@hc-tfe-release-bot** [tfe-task-worker#785](https://github.com/hashicorp/tfe-task-worker/pull/785)
