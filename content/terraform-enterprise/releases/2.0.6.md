## Features

1.Redis mTLS connections now support password authentication. Both can be enabled at the same time - certificate-based mutual TLS and Redis ACL credentials.

## Improvements

1. Task worker metadata has been updated to include information about `terraform destroy` calls. -- **@JenGoldstrich** [terraform-enterprise#5122](https://github.com/hashicorp/terraform-enterprise/pull/5122)
1. New configuration options for upload concurrency and upload part size are supported in Azure. TFE customers, who have the option to configure their own storage solution behind Archivist

## Bug Fixes

1. Terraform Enterprise now reaps zombie processes.
1. Background migrations properly handle non-semver versions. Previously a background migration with an errant where clause would fail to parse a version. `An error occurred when inspecting the object: #<ActiveRecord::StatementInvalid:"PG::InvalidTextRepresentation: ERROR:  invalid input syntax for type integer: test-1-1`.  This would prevent background migrations from running, such as those that populate the Explorer database -- **@hc-tfe-release-bot** [atlas#30801](https://github.com/hashicorp/atlas/pull/30801)
1. Terraform stacks respects no_proxy environment variable configuration.  Previously stacks runs were ignoring no_proxy configuration.
