If the **Site Auditor** permission is enabled for your account, then you can send `GET` requests to access resource data. If your permissions also include write access, then you can send other kinds of requests that allow you to modify data per the scope of your team membership. Refer to [Assign site auditor permissions](/terraform/enterprise/application-administration/resources#assign-site-auditor-permission) for more information.
