| Mode | Description | Default |
|------|-------------|---------|
| `port` | Admin console accessible only via dedicated port (e.g., `:8443`) | ✅ Yes |
| `path` | Admin console accessible only via standard HTTPS path (`/platform/admin`) | No |
| `both` | Admin console accessible via both dedicated port and standard HTTPS path | No |
| `disabled` | Admin console is disabled and inaccessible | No |
| (unset) | Falls back to the value of `TFE_ADMIN_CONSOLE_DISABLED`. If `TFE_ADMIN_CONSOLE_DISABLED` is `true`, the console is disabled; otherwise, behavior is equivalent to `port` | No |

By default, you can only access the admin console through the dedicated port. This provides network-level isolation, as you can block the dedicated port at the firewall or load balancer level to restrict access to authorized networks or IP addresses.
