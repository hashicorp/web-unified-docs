# Admin User Tokens API

The `admin/user-tokens` API lets site administrators list and delete user API tokens across all users in a Terraform Enterprise installation.

-> **Terraform Enterprise Only:** The admin API is exclusive to Terraform Enterprise, and can only be used by the admins and operators who install and maintain their organization's Terraform Enterprise instance.

## List all user tokens

`GET /api/v2/admin/user-tokens`

This endpoint lists all user API tokens across all users in the Terraform Enterprise installation.

| Status  | Response                                                        | Reason                          |
| ------- | --------------------------------------------------------------- | ------------------------------- |
| [200][] | [JSON API document][] (`type: "authentication-tokens"`)         | Successfully listed user tokens |
| [404][] | [JSON API error object][]                                       | Client is not an administrator. |

### Query Parameters

[These are standard URL query parameters](/terraform/enterprise/api-docs#query-parameters). Remember to percent-encode `[` as `%5B` and `]` as `%5D` if your tooling doesn't automatically encode URLs.

| Parameter               | Description                                                                                                                                                             |
| ----------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `filter[expiry_status]` | **Optional.** Comma-separated list of expiry statuses to filter by. Accepted values: `active`, `expiring_in_7_days`, `expiring_in_30_days`, `expired`, `no_expiration`. |
| `sort`                  | **Optional.** Sort results by a token attribute. Accepted values: `expired-at`, `-expired-at`, `last-used-at`, `-last-used-at`. Prefix with `-` for descending order.   |
| `page[number]`          | **Optional.** If omitted, the endpoint returns the first page.                                                                                                          |
| `page[size]`            | **Optional.** If omitted, the endpoint returns 20 tokens per page.                                                                                                      |

### Sample Request

```shell
curl \
  --header "Authorization: Bearer $TOKEN" \
  --header "Content-Type: application/vnd.api+json" \
  "https://<TFE_HOSTNAME>/api/v2/admin/user-tokens"
```

### Sample Request with Filters

```shell
curl \
  --header "Authorization: Bearer $TOKEN" \
  --header "Content-Type: application/vnd.api+json" \
  "https://<TFE_HOSTNAME>/api/v2/admin/user-tokens?filter%5Bexpiry_status%5D=expired,expiring_in_7_days&sort=-expired-at"
```

## Delete a user token

`DELETE /api/v2/admin/user-tokens/:token_id`

This endpoint deletes a single user API token.

-> **Note:** Administrators cannot delete their own token using this endpoint. Self-deletion is blocked; use the [user tokens API](/terraform/enterprise/api-docs/user-tokens) to manage your own tokens.

| Parameter   | Description                    |
| ----------- | ------------------------------ |
| `:token_id` | The ID of the token to delete. |

| Status  | Response                  | Reason                                                        |
| ------- | ------------------------- | ------------------------------------------------------------- |
| [204][] | Empty body                | Successfully deleted the token.                               |
| [403][] | [JSON API error object][] | The requesting admin cannot delete their own token.           |
| [404][] | [JSON API error object][] | Token not found, or client is not an administrator.           |

### Sample Request

```shell
curl \
  --header "Authorization: Bearer $TOKEN" \
  --header "Content-Type: application/vnd.api+json" \
  --request DELETE \
  "https://<TFE_HOSTNAME>/api/v2/admin/user-tokens/at-QoKZi25LmA1RDfzR"
```

## Bulk-delete user tokens

`DELETE /api/v2/admin/user-tokens`

This endpoint bulk-deletes up to 100 user API tokens in a single atomic operation. Either all tokens are deleted or none are, so a partial failure will not leave the system in an inconsistent state.

-> **Note:** The maximum number of tokens that can be deleted in a single request is 100. Requests that specify more than 100 token IDs will be rejected. Administrators cannot include their own token in a bulk-delete request. Self-deletion is blocked; use the [user tokens API](/terraform/enterprise/api-docs/user-tokens) to manage your own tokens.

| Status  | Response                  | Reason                                                                |
| ------- | ------------------------- | --------------------------------------------------------------------- |
| [204][] | Empty body                | Successfully deleted all specified tokens.                            |
| [400][] | [JSON API error object][] | Request exceeds the 100-token limit, or the request body is invalid.  |
| [403][] | [JSON API error object][] | The request includes the requesting admin's own token.                |
| [404][] | [JSON API error object][] | One or more token IDs not found, or client is not an administrator.   |
| [422][] | [JSON API error object][] | Validation errors.                                                    |

### Request Body

This DELETE endpoint requires a JSON object with the following properties as a request payload.

| Key path      | Type             | Default | Description                                    |
| ------------- | ---------------- | ------- | ---------------------------------------------- |
| `data`        | array of objects |         | An array of token resource identifier objects. |
| `data[].type` | string           |         | Must be `"authentication-tokens"`.             |
| `data[].id`   | string           |         | The ID of the token to delete.                 |

### Sample Payload

```json
{
  "data": [
    {
      "type": "authentication-tokens",
      "id": "at-QoKZi25LmA1RDfzR"
    },
    {
      "type": "authentication-tokens",
      "id": "at-Ry7nKpL3bXwTmJ9Q"
    }
  ]
}
```

### Sample Request

```shell
curl \
  --header "Authorization: Bearer $TOKEN" \
  --header "Content-Type: application/vnd.api+json" \
  --request DELETE \
  --data @payload.json \
  "https://<TFE_HOSTNAME>/api/v2/admin/user-tokens"
```
