# Configure cluster port

Port 443 Access is a self-service setting that lets you enable or disable client connectivity to your HCP Vault Dedicated cluster over port 443 directly from the HCP portal.

Port 443 access is useful for organizations that restrict outbound traffic to standard HTTPS ports, making it easier to connect applications and services to Vault without requiring additional firewall exceptions or network configuration changes.

You can enable or disable port 443 access at any time without opening a support request by navigating to the port 443 access toggle by clicking on port 443 under Cluster Details

## Enable or disable port 443 access

1. Navigate to your HCP Vault Dedicated cluster.
1. Open the cluster configuration settings.
1. Locate **Port 443 Access**.
1. Turn the toggle **On** to enable access or **Off** to disable access.
1. Confirm the change.

## What happens when the setting changes

When you change the Port 443 Access setting:

- HCP automatically updates the cluster configuration.
- Progress and status are displayed in the HCP portal.
- Port 443 access is enabled or removed based on the selected state.
- Any configuration errors are surfaced in the HCP portal.
