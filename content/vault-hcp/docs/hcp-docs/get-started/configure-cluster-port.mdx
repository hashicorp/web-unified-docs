# Configure cluster port

Vault clusters listen on port 8200 by default. For use cases that do not allow
access on port 8200, you can change your HCP Vault Cluster to listen on the
standard HTTPS port 443.

Access on port 443 is useful for organizations that restrict outbound traffic to
standard HTTPS ports, making it easier to connect applications and services to
Vault without requiring additional firewall exceptions or network configuration
changes.

You can enable or disable port 443 access at any time without opening a support
request by navigating to the port 443 access toggle by clicking on port 443
under **Cluster Details**.

## Configure port 443 access

1. Navigate to your HCP Vault Dedicated cluster.

1. Open the cluster configuration settings.

1. Locate **Port 443 Access**.

1. Turn the toggle **On** to enable access or **Off** to disable access.

1. Confirm the change.

After you change the **Port 443 Access** setting, HCP automatically updates the
cluster configuration. You can monitor progress in the HCP portal.
