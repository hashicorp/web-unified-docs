Boundary creates new OIDC auth methods in an `inactive` state. You must activate the auth method before users can log in with it.

<Tabs>
<Tab heading="UI" group="ui">

1. Log in to Boundary.
1. Select **Auth Methods**, then select the OIDC auth method you created.
1. Select **Manage**, then select **Change State**.
1. Select **Active Public** to allow unauthenticated users to see and use the auth method to log in, or select **Active Private** to allow login without listing the auth method on the login page.

</Tab>
<Tab heading="CLI" group="cli">

Use the `auth-methods change-state` command to activate the auth method:

```shell-session
$ boundary auth-methods change-state oidc \
  -id $OIDC_AUTH_METHOD_ID \
  -state active-public
```

Before Boundary changes the state of an auth method, it retrieves the provider's discovery document for the auth method's issuer and validates the auth method's configuration against it. If Boundary cannot validate the configuration, it returns an error and does not change the state.

Refer to the [auth-methods change-state](/boundary/docs/commands/auth-methods/change-state) command documentation for more information about auth method states.

</Tab>
<Tab heading="Terraform" group="terraform">

Set the `state` attribute on the `boundary_auth_method_oidc` resource so that Terraform activates the auth method when it applies the configuration:

```hcl
resource "boundary_auth_method_oidc" "provider" {
  # ...
  state = "active-public"
}
```

</Tab>
</Tabs>

### Set the auth method as primary

Each scope has one primary auth method. Boundary automatically creates a user the first time someone authenticates successfully using the scope's primary auth method.

If the auth method is not primary for its scope, Boundary creates an account when a user first logs in, but it refuses to create the matching user, and the login fails. Either set the auth method as primary, as described in this section, or [manually create a user and link it to the account](/boundary/docs/rbac/users/manage-users-groups).

<Tabs>
<Tab heading="UI" group="ui">

1. Select **Auth Methods**, then select the OIDC auth method.
1. Select **Manage**, then select **Make Primary**.
1. Select **OK** to confirm. Boundary automatically creates a user for anyone who authenticates using this auth method for the first time.

</Tab>
<Tab heading="CLI" group="cli">

```shell-session
$ boundary scopes update \
  -id $SCOPE_ID \
  -primary-auth-method-id $OIDC_AUTH_METHOD_ID
```

</Tab>
<Tab heading="Terraform" group="terraform">

Set the `is_primary_for_scope` attribute on the `boundary_auth_method_oidc` resource:

```hcl
resource "boundary_auth_method_oidc" "provider" {
  # ...
  is_primary_for_scope = true
}
```

</Tab>
</Tabs>
