This example is equivalent to the default settings if no `audit_config` stanza
is provided.

```hcl
audit_config {
  audit_filter_overrides {
    sensitive = "redact"
    secret    = "redact"
  }
}
```

This example will HMAC sensitive fields, and encrypt secrets.

```hcl
audit_config {
  audit_filter_overrides {
    sensitive = "hmac-sha256"
    secret    = "encrypt"
  }
}
```

This example will not apply a filter to sensitive fields.

<Note>  

Boundary considers email addresses and usernames to be sensitive. 
To include these fields in event sink output,  
set `sensitive` to an empty string in the `audit_filter_overrides` block in the  
following example. The empty string overrides the default filter for sensitive fields.

</Note>  

```hcl
audit_config {
  audit_filter_overrides {
    sensitive = ""
  }
}
```
