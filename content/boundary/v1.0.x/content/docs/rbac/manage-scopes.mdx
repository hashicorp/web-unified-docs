# Manage scopes

Scopes group Boundary resources. You can update the name or description of an org or project scope, or delete a scope and the resources it contains.

When Terraform manages a scope, update or delete it in Terraform. Making the same change in the Admin console or CLI can cause the next Terraform plan to report drift.

## Requirements

- You have a role with permission to update or delete the scope. Refer to [Resource tables](/boundary/docs/rbac/resource-table) and [Manage access with roles](/boundary/docs/rbac/manage-roles).
- You have logged in to Boundary when you use the Admin console or CLI.
- You have configured the [Terraform Boundary provider](/boundary/docs/deploy/terraform-patterns/#terraform-provider-configuration) when you use Terraform.

## Update a scope

You can update the name or description of an existing org or project scope.

Complete the following steps to update a scope:

<Tabs>
<Tab heading="Admin console" group="admin">

Select whether you want to update an org scope or a project scope:

<Tabs>
<Tab heading="Org scope">

1. Log in to Boundary.
1. Select **Orgs** in the navigation pane, and then select the org scope that you want to update.
1. Select **Org Settings** in the navigation pane.
1. Click **Edit Form**.
1. Update the **Name** or **Description** fields.
1. Click **Save**.

</Tab>
<Tab heading="Project scope">

1. Log in to Boundary.
1. Select **Orgs** in the navigation pane, and then select the org scope that contains the project scope.
1. Select the project scope that you want to update.
1. Select **Project Settings** in the navigation pane.
1. Click **Edit Form**.
1. Update the **Name** or **Description** fields.
1. Click **Save**.

</Tab>
</Tabs>

</Tab>
<Tab heading="CLI" group="cli">

1. Log in to Boundary.
1. Run the `scopes update` command with the scope ID and the values you want to change:

   ```shell-session
   $ boundary scopes update \
       -id ORG_SCOPE_ID \
       -name "operations" \
       -description "Org scope for the operations team"
   ```

   Replace `ORG_SCOPE_ID` with a project scope ID when you update a project scope. You can also use the `-primary-auth-method-id` option to set the scope's primary auth method.
1. Confirm that the scope reflects the updated values.

For the full set of supported options, refer to [`scopes update`](/boundary/docs/commands/scopes/update).

</Tab>
<Tab heading="Terraform" group="terraform">

Use the following steps for an org scope or a project scope:

1. Update the `name` or `description` attribute in the existing `boundary_scope` resource:

```hcl
resource "boundary_scope" "project" {
  name        = "operations"
  description = "Project scope for shared operations systems"
  scope_id    = boundary_scope.org.id
}
```

1. Review the proposed in-place update:

   ```shell-session
   $ terraform plan
   ```

1. Apply the change:

   ```shell-session
   $ terraform apply
   ```

Terraform updates the scope in place.

</Tab>
</Tabs>

## Delete a scope

<Warning>
Deleting a scope also deletes the resources it contains, including nested scopes and their resources. This operation cannot be undone. Review the scope and its resources before you delete it.
</Warning>

You cannot delete the `global` scope.

Complete the following steps to delete an org or project scope:

<Tabs>
<Tab heading="Admin console" group="admin">

Select whether you want to delete an org scope or a project scope:

<Tabs>
<Tab heading="Org scope">

1. Log in to Boundary.
1. Select **Orgs** in the navigation pane, and then select the org scope that you want to delete.
1. Select **Org Settings** in the navigation pane.
1. Click **Manage**, and then select **Delete**.
1. Click **Delete** to confirm.

</Tab>
<Tab heading="Project scope">

1. Log in to Boundary.
1. Select **Orgs** in the navigation pane, and then select the org scope that contains the project scope.
1. Select the project scope that you want to delete.
1. Select **Project Settings** in the navigation pane.
1. Click **Manage**, and then select **Delete**.
1. Click **Delete** to confirm.

</Tab>
</Tabs>

</Tab>
<Tab heading="CLI" group="cli">

1. Log in to Boundary.
1. Run the `scopes delete` command with the scope ID:

   ```shell-session
   $ boundary scopes delete -id PROJECT_SCOPE_ID
   ```

   Replace `PROJECT_SCOPE_ID` with an org scope ID when you delete an org scope.
1. Confirm that Boundary no longer lists the scope.

For the full command reference, refer to [`scopes delete`](/boundary/docs/commands/scopes/delete).

</Tab>
<Tab heading="Terraform" group="terraform">

1. Remove the `boundary_scope` resource from your Terraform configuration.
1. Run `terraform plan` and review the scope and any child resources that Terraform plans to destroy.
1. Run `terraform apply` to delete the scope.

</Tab>
</Tabs>
