# Configure MCP clients for the Boundary MCP server

This page describes how to configure an MCP client to connect to a running Boundary MCP server.

@include 'alerts/beta.mdx'

The configuration format depends on how you are running the server:

- **Binary (`stdio`):** Your client launches the binary directly. Use this configuration if you run the server from the [pre-built binary](/boundary/docs/mcp-server/run#run-from-the-binary).
- **Docker (Streamable HTTP):** Your client connects to `http://localhost:8080`. Use this configuration if you run the server using [Docker](/boundary/docs/mcp-server/run#run-with-docker).

## Requirements

- A running Boundary MCP server. Refer to [Run the Boundary MCP server](/boundary/docs/mcp-server/run) for instructions.
- A Boundary token for the user connecting from this client. The controller enforces role-based access control on every request using this token, so use a token with only the permissions that user needs. Refer to [Permissions in Boundary](/boundary/docs/rbac) for more information.
- Your Boundary controller address, for example `https://cluster.boundary.hashicorp.cloud:9200`.

## Binary configuration

If you installed the server from the pre-built binary, add the following configuration to your MCP client settings. Replace `/path/to/boundary-mcp-server` with the path to the binary, `<<BOUNDARY_TOKEN_HERE>>` with your Boundary token, and `<<BOUNDARY_ADDR_HERE>>` with your Boundary controller address.

```json
{
  "mcp": {
    "servers": {
      "boundary": {
        "type": "stdio",
        "command": "/path/to/boundary-mcp-server",
        "env": {
          "BOUNDARY_TOKEN": "<<BOUNDARY_TOKEN_HERE>>",
          "BOUNDARY_ADDR": "<<BOUNDARY_ADDR_HERE>>"
        }
      }
    }
  }
}
```

## Docker configuration

If you are running the server with Docker, select your MCP client and add the configuration to its settings file. Replace `<<BOUNDARY_TOKEN_HERE>>` with your Boundary token and `<<BOUNDARY_ADDR_HERE>>` with your Boundary controller address.

<Tabs>

<Tab heading="IBM Bob" group="bob">

Add the following configuration to your Bob MCP settings. Refer to [Using MCP in Bob](https://bob.ibm.com/docs/ide/configuration/mcp/mcp-in-bob) for the location of the settings file.

```json
{
  "mcpServers": {
    "boundary": {
      "type": "http",
      "url": "http://localhost:8080",
      "headers": {
        "BOUNDARY_TOKEN": "<<BOUNDARY_TOKEN_HERE>>",
        "BOUNDARY_ADDR": "<<BOUNDARY_ADDR_HERE>>"
      },
      "disabled": false
    }
  }
}
```

</Tab>

<Tab heading="VS Code" group="vscode">

You can configure the server in your user settings or in a workspace settings file.

**User settings**

Press `Ctrl+Shift+P`, type `Preferences: Open User Settings (JSON)`, and add the following configuration. Refer to the [VS Code MCP documentation](https://code.visualstudio.com/docs/copilot/chat/mcp-servers) for more information.

```json
{
  "mcp": {
    "servers": {
      "boundary": {
        "type": "http",
        "url": "http://localhost:8080",
        "headers": {
          "BOUNDARY_TOKEN": "${input:boundary-token}",
          "BOUNDARY_ADDR": "${input:boundary-addr}"
        }
      }
    },
    "inputs": [
      {
        "type": "promptString",
        "id": "boundary-token",
        "description": "Boundary API Token",
        "password": true
      },
      {
        "type": "promptString",
        "id": "boundary-addr",
        "description": "Boundary Controller Address (e.g. https://cluster.boundary.hashicorp.cloud:9200)",
        "password": false
      }
    ]
  }
}
```

**Workspace settings**

To share the configuration with your team, create a `.vscode/mcp.json` file in your workspace and add the following configuration:

```json
{
  "servers": {
    "boundary": {
      "type": "http",
      "url": "http://localhost:8080",
      "headers": {
        "BOUNDARY_TOKEN": "${input:boundary-token}",
        "BOUNDARY_ADDR": "${input:boundary-addr}"
      }
    }
  },
  "inputs": [
    {
      "type": "promptString",
      "id": "boundary-token",
      "description": "Boundary API Token",
      "password": true
    },
    {
      "type": "promptString",
      "id": "boundary-addr",
      "description": "Boundary Controller Address (e.g. https://cluster.boundary.hashicorp.cloud:9200)",
      "password": false
    }
  ]
}
```

After you add the configuration, open Copilot Chat and switch to **Agent** mode to use the MCP server.
