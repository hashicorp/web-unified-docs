# Boundary MCP server configuration reference

This page describes the environment variables, CLI flags, HTTP headers, and toolsets available for configuring the Boundary MCP server.

@include 'alerts/beta.mdx'

## Environment variables

Use the following environment variables to configure the server at startup. CLI flags override environment variables when both are set.

| Variable | Description | Default |
| --- | --- | --- |
| `BOUNDARY_ADDR` | Boundary controller address, for example `https://cluster.boundary.hashicorp.cloud:9200`. In remote mode, clients can supply this value in the `BOUNDARY_ADDR` HTTP header instead. | `""` |
| `BOUNDARY_TOKEN` | Boundary API token. In remote mode, the server ignores this variable and requires clients to supply the token in the `BOUNDARY_TOKEN` HTTP header on every request. | `""` |
| `BOUNDARY_MCP_ADDR` | Listen address for the MCP HTTP server. Overridden by the `--addr` flag. | `127.0.0.1:8080` |
| `BOUNDARY_MCP_TLS_CERT` | Path to a TLS certificate file. When set, the server enables TLS on the HTTP transport. | `""` |
| `LOG_LEVEL` | Logging verbosity. Accepted values: `trace`, `debug`, `info`, `warn`, `error`, `fatal`, `panic`. | `info` |
| `LOG_FORMAT` | Logging output format. Accepted values: `text`, `json`. | `text` |

<Note>

Configuring TLS using `BOUNDARY_MCP_TLS_CERT` requires a corresponding TLS key path. Engineering confirmation is pending on how to supply the key.

</Note>

## CLI flags

Use the following flags when starting the server from the command line.

| Flag | Description | Default |
| --- | --- | --- |
| `--mode` | Deployment topology. `local` runs the server on the operator's machine and enables the `connect` toolset. `remote` disables the process-environment token fallback and never registers `connect`. | `local` |
| `--token-revalidation-interval` | Minimum interval between controller revalidations of a session token on `tools/call`. Set to `0` to revalidate on every call. Negative values are rejected. | `30s` |
| `--toolsets` | Comma-separated toolset names or a keyword (`default`, `read-only`, `all`). Mutually exclusive with `--tools`. | `default` |
| `--tools` | Comma-separated individual tool names. Bypasses toolset grouping. Mutually exclusive with `--toolsets`. | `""` |
| `--addr` | Listen address for the MCP HTTP server, for example `127.0.0.1:8080`. Overrides `BOUNDARY_MCP_ADDR`. | `127.0.0.1:8080` |
| `--log-level` | Logging verbosity. Accepted values: `trace`, `debug`, `info`, `warn`, `error`, `fatal`, `panic`. Overrides `LOG_LEVEL`. | `info` |
| `--log-format` | Logging output format. Accepted values: `text`, `json`. Overrides `LOG_FORMAT`. | `text` |
| `--log-file` | Write logs to this file instead of stderr. | `""` |

## HTTP headers

When running the server in remote mode, clients pass the following HTTP headers on each request.

| Header | Description |
| --- | --- |
| `BOUNDARY_TOKEN` | Boundary API token for the requesting user. Required in remote mode. |
| `BOUNDARY_ADDR` | Boundary controller address. Accepted only in remote mode when not set server-side. |

## Toolsets

A toolset is a named group of related tools. Use the `--toolsets` flag to enable one or more toolsets by name, or use a keyword to enable a predefined combination.

### Keywords

| Keyword | Toolsets enabled |
| --- | --- |
| `default` | `targets`, `sessions` |
| `read-only` | All read toolsets (no admin toolsets) |
| `all` | All toolsets, including admin and `connect` |

### Available toolsets

| Toolset | Description |
| --- | --- |
| `targets` | List and read targets |
| `targets-admin` | Create, update, and delete targets; manage credential and host source associations |
| `sessions` | List and read sessions |
| `sessions-admin` | Cancel sessions |
| `users` | List and read users |
| `users-admin` | Create, update, and delete users; manage account associations |
| `workers` | List and read workers |
| `workers-admin` | Update and delete workers |
| `scopes` | List and read scopes |
| `scopes-admin` | Create, update, and delete scopes |
| `accounts` | List and read accounts |
| `accounts-admin` | Create, update, and delete accounts |
| `authmethods` | List and read auth methods |
| `authmethods-admin` | Create, update, and delete auth methods |
| `groups` | List and read groups |
| `groups-admin` | Create, update, and delete groups; manage members |
| `roles` | List and read roles |
| `roles-admin` | Create, update, and delete roles; manage grants and principals |
| `hosts` | List and read hosts |
| `hosts-admin` | Create, update, and delete hosts |
| `hostsets` | List and read host sets |
| `hostsets-admin` | Create, update, and delete host sets; manage hosts |
| `hostcatalogs` | List and read host catalogs |
| `hostcatalogs-admin` | Create, update, and delete host catalogs |
| `credentials` | List and read credentials |
| `credentials-admin` | Create, update, and delete credentials |
| `credentialstores` | List and read credential stores |
| `credentialstores-admin` | Create, update, and delete credential stores |
| `credentiallibraries` | List and read credential libraries |
| `credentiallibraries-admin` | Create, update, and delete credential libraries |
| `managedgroups` | List and read managed groups |
| `managedgroups-admin` | Create, update, and delete managed groups |
| `sessionrecordings` | List and read session recordings |
| `storagebuckets` | List and read storage buckets |
| `storagebuckets-admin` | Create, update, and delete storage buckets |
| `aliases` | List and read aliases |
| `aliases-admin` | Create, update, and delete aliases |
| `policies` | List and read policies |
| `policies-admin` | Create, update, and delete policies |
| `connect` | Establish a local proxy session to a target. Available in local mode only. |

For details on which operations are not supported due to secret-handling restrictions, refer to the [Boundary MCP server overview](/boundary/docs/mcp-server#unsupported-operations).
