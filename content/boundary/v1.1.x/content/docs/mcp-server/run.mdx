# Run the Boundary MCP server

This page describes how to run the Boundary MCP server. After the server is running, refer to [Configure MCP clients for the Boundary MCP server](/boundary/docs/mcp-server/configure-clients) to connect your MCP client.

@include 'alerts/beta.mdx'

You can run the server in two ways, depending on your environment:

- **Binary:** Downloads a pre-built binary from the [HashiCorp releases page](https://releases.hashicorp.com/boundary-mcp-server). The binary uses the `stdio` transport and communicates directly with your MCP client over standard input and output.
- **Docker:** Builds a container image locally from the downloaded source archive and runs the server over the Streamable HTTP transport on `localhost:8080`.

## Requirements

- A running HCP Boundary cluster or Boundary Enterprise deployment.
- A Boundary token with permissions for the resources you want to manage. Refer to [Permissions in Boundary](/boundary/docs/rbac) for more information.
- An MCP client that supports either the Streamable HTTP or `stdio` transport. Verified clients include Visual Studio Code, Cursor, Claude Desktop, Amazon Q Developer, and IBM Bob.

## Run from the binary

Download and run the pre-built binary when you want to run the server directly without Docker. The binary uses the `stdio` transport.

### Install the binary

1. Download the binary for your operating system and architecture from the [HashiCorp releases page](https://releases.hashicorp.com/boundary-mcp-server).

1. Move the binary to a directory in your `PATH` and make it executable. For example, on Linux or macOS:

   ```shell-session
   $ mv boundary-mcp-server /usr/local/bin/
   $ chmod +x /usr/local/bin/boundary-mcp-server
   ```

1. Verify the installation:

   ```shell-session
   $ boundary-mcp-server --version
   ```

## Run with Docker

Use Docker when you prefer a containerized deployment. The Docker method builds the image locally from the downloaded source archive. The server uses the Streamable HTTP transport and listens on port `8080`.

### Requirements

- [Docker](https://www.docker.com/)
- [Make](https://www.gnu.org/software/make/)

### Build and run the server

1. Download the source archive for your target version from the [HashiCorp releases page](https://releases.hashicorp.com/boundary-mcp-server) and extract it:

   ```shell-session
   $ tar -xzf boundary-mcp-server_<version>.tar.gz
   $ cd boundary-mcp-server_<version>
   ```

1. Build the Docker image:

   ```shell-session
   $ make docker-build
   ```

1. Run the server, replacing `<<BOUNDARY_ADDR_HERE>>` with your Boundary controller address, for example `https://cluster.boundary.hashicorp.cloud:9200`:

   ```shell-session
   $ docker run -p 127.0.0.1:8080:8080 --rm \
       -e BOUNDARY_ADDR=<<BOUNDARY_ADDR_HERE>> \
       boundary-mcp-server:dev
   ```

1. Confirm the server is running:

   ```shell-session
   $ curl http://localhost:8080/health
   ```
