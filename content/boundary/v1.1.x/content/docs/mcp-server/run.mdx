# Run the Boundary MCP server

This page describes how to run the Boundary MCP server. After the server is running, refer to [Configure MCP clients for the Boundary MCP server](/boundary/docs/mcp-server/configure-clients) to connect your MCP client.

@include 'alerts/beta.mdx'

You can run the server in two ways, depending on your environment:

- **Go binary:** Installs the server as a binary using `go install`. The binary uses the `stdio` transport and communicates directly with your MCP client over standard input and output.
- **Docker:** Builds a container image locally and runs the server over the Streamable HTTP transport on `localhost:8080`.

## Requirements

- A running HCP Boundary cluster or Boundary Enterprise deployment.
- A Boundary token with permissions for the resources you want to manage. Refer to [Permissions in Boundary](/boundary/docs/rbac) for more information.
- An MCP client that supports either the Streamable HTTP or `stdio` transport. Verified clients include Visual Studio Code, Cursor, Claude Desktop, Amazon Q Developer, and IBM Bob.

## Run from a Go binary

Use `go install` when you have Go installed and want to run the server directly as a binary. The binary uses the `stdio` transport.

### Requirements

- [Go](https://go.dev/dl/) 1.26.4 or later.

### Install the binary

Run the following command to install the latest released version of the MCP server:

```console
$ go install github.com/hashicorp/boundary-mcp-server/cmd/boundary-mcp-server@latest
```

To install from the main branch instead, run the following command:

```console
$ go install github.com/hashicorp/boundary-mcp-server/cmd/boundary-mcp-server@main
```

## Run with Docker

Use Docker when you do not have Go installed or prefer a containerized deployment. The Docker method builds the image locally from the source repository. The server uses the Streamable HTTP transport and listens on port `8080`.

### Requirements

- [Git](https://git-scm.com/)
- [Docker](https://www.docker.com/)
- [Make](https://www.gnu.org/software/make/)

### Build and run the server

1. Clone the repository and change into its directory:

   ```shell-session
   $ git clone https://github.com/hashicorp/boundary-mcp-server.git
   $ cd boundary-mcp-server
   ```

1. Build the Docker image:

   ```shell-session
   $ make docker-build
   ```

1. Run the server, replacing `<<BOUNDARY_ADDR_HERE>>` with your Boundary controller address, for example `https://cluster.boundary.hashicorp.cloud:9200`:

   ```shell-session
   $ docker run -p 127.0.0.1:8080:8080 --rm \
       -e BOUNDARY_ADDR=<<BOUNDARY_ADDR_HERE>> \
       boundary-mcp-server:dev
   ```

1. Confirm the server is running:

   ```shell-session
   $ curl http://localhost:8080/health
   ```
