# authenticate jwt

Command: `boundary authenticate jwt`

The `authenticate jwt` command exchanges a signed JSON Web Token (JWT) for a Boundary auth token using the JWT auth method.

@include 'alerts/beta.mdx'

## Example

The following example uses a JWT auth method with the ID `amjwt_1234567890` to authenticate, reading the JWT from an environment variable:

```shell-session
$ boundary authenticate jwt \
  -auth-method-id amjwt_1234567890 \
  -jwt-token env://WORKLOAD_JWT
```

## Usage

<CodeBlockConfig hideClipboard>

```shell-session
$ boundary authenticate jwt [options] [args]
```

</CodeBlockConfig>

### Command options

- `-auth-method-id` `(string: "")` - The ID of the JWT auth method to use for authentication. You can also specify the auth method using the `BOUNDARY_AUTH_METHOD_ID` environment variable.

- `-jwt-token` `(string: "")` - The signed JWT to present for authentication. This value must use the `env://` or `file://` scheme to reference the JWT from an environment variable or file. Do not pass the raw JWT directly as a flag value. You can also supply the JWT using the `BOUNDARY_AUTHENTICATE_JWT_TOKEN` environment variable. Use this variable when authenticating against a scope's primary auth method with `boundary authenticate`.

- `-scope-id` `(string: "")` - The scope ID to use for the operation. You can also specify the scope ID using the `BOUNDARY_SCOPE_ID` environment variable.
