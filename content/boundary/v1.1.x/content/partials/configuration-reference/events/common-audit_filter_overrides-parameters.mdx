- `sensitive` `(string: "", "encrypt", "hmac-sha256", "redact")` - Specifies
    the filter operation to apply to fields that are classified as sensitive. Sensitive fields are values containing identity
revealing data like IP addresses and usernames.

- `secret` `(string: "", "encrypt", "hmac-sha256", "redact")` - Specifies
    the filter operation to apply to fields that are classified as secret. Secret fields are values such
as credentials, passwords, tokens, and other information that could be exploited if exposed.
