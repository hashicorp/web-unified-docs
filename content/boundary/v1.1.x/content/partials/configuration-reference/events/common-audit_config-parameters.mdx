- `audit_filter_overrides` - Specifies overrides for the filter operations that
    are applied to audit events. The available filter override operations are:

    - `""` (empty string): No filter operation is applied, and the field will be logged in plaintext.
    - `"encrypt"`: The field will be encrypted before being logged.
    - `"hmac-sha256"`: The field will be hashed using HMAC-SHA256 before being logged.
    - `"redact"`: The field will be redacted and not logged at all.
