# `nomad queue` command reference

The `queue` command inspects the batch job queue of a node pool.

## Usage

```plaintext
nomad queue <subcommand> [options]
```

## Description

A batch job queue holds the batch jobs registered in a node pool and sends them
to the scheduler one at a time. Use the `queue` subcommands to view the jobs
waiting in a queue and the resource usage of each tenant in a dynamic priority
queue. Refer to [Batch job queue](/nomad/docs/concepts/scheduling/batch-job-queue)
for details about how queues work.

## Subcommands

Run `nomad queue <subcommand> -h` for help on that subcommand. The following
subcommands are available.

- [`queue jobs`][jobs] lists the jobs in a batch job queue.

- [`queue tenants`][tenants] lists the tenants in a dynamic priority batch job
  queue and their resource usage.
