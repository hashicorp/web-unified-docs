# `nomad queue status` command reference

The `queue status` command reports the status of the batch job queue of a node
pool. For a dynamic priority queue, the command lists the tenants and their
allocated resources.

## Usage

```plaintext
nomad queue status [options]
```

For a dynamic priority queue, the `queue status` command lists each tenant that
the queue tracks. For each tenant, the command shows the CPU in MHz and the
memory in MB that Nomad allocated to the tenant's batch jobs next to the total
for all tenants, and the tenant's percentage of the total. Refer to [Tenant
fairshare](/nomad/docs/concepts/scheduling/batch-job-queue#tenant-fairshare)
for details.

The command reports status for dynamic priority queues only. For a FIFO queue,
the command returns `Queue type "fifo" does not implement status` and exits
with code `255`. When the node pool does not have a batch job queue, the command
returns `No batch job queue configured`.

When ACLs are enabled, this command requires a token with `operator:read`
permissions.

## Options

- `-node-pool`: The node pool whose queue to inspect. This flag is required.

- `-json`: Output the status in JSON format.

## Examples

View the status of the dynamic priority queue of the `batch` node pool.

```shell-session
$ nomad queue status -node-pool batch
Batch Queue Status
Tenant  Resource  Current / Total  Percentage
team-a                             100
        cpu       600.00 / 600.00
        memory    256.00 / 256.00
team-b                             0
        cpu       0.00 / 600.00
        memory    0.00 / 256.00
```

View the status in JSON format.

```shell-session
$ nomad queue status -node-pool batch -json
[{"PercentageUsed":100,"TenantFairshare":{"cpu":600,"memory":256},"TenantID":"team-a","TotalFairshare":{"cpu":600,"memory":256}},{"PercentageUsed":0,"TenantFairshare":{"cpu":0,"memory":0},"TenantID":"team-b","TotalFairshare":{"cpu":600,"memory":256}}]
```
