# `nomad queue tenants` command reference

The `queue tenants` command lists the tenants in the dynamic priority batch job
queue of a node pool and their allocated resources.

## Usage

```plaintext
nomad queue tenants [options]
```

The `queue tenants` command lists each tenant that the queue tracks. For each
tenant, the command shows the CPU in MHz and the memory in MB that Nomad
allocated to the tenant's batch jobs next to the total for all tenants, and the
tenant's percentage of the total. Refer to [Tenant
fairshare](/nomad/docs/concepts/scheduling/batch-job-queue#tenant-fairshare)
for details.

The command reports tenants for dynamic priority queues only.

When ACLs are enabled, this command requires a token with `operator:read`
permissions.

## Options

- `-node-pool`: The node pool whose queue to inspect. Defaults to `default`.

- `-json`: Output the tenants in JSON format.

## Examples

List the tenants in the dynamic priority queue of the `batch` node pool.

```shell-session
$ nomad queue tenants -node-pool batch
Batch Queue Tenants
Tenant  Resource  Current / Total  Percentage
team-a                             100
        cpu       600.00 / 600.00
        memory    256.00 / 256.00
team-b                             0
        cpu       0.00 / 600.00
        memory    0.00 / 256.00
```

List the tenants in JSON format.

```shell-session
$ nomad queue tenants -node-pool batch -json
[{"PercentageUsed":100,"TenantFairshare":{"cpu":600,"memory":256},"TenantID":"team-a","TotalFairshare":{"cpu":600,"memory":256}},{"PercentageUsed":0,"TenantFairshare":{"cpu":0,"memory":0},"TenantID":"team-b","TotalFairshare":{"cpu":600,"memory":256}}]
```
