# `nomad queue tenants` command reference

The `queue tenants` command lists the tenants in the dynamic priority batch job
queue of a node pool and their recent resource usage.

## Usage

```plaintext
nomad queue tenants [options]
```

The `queue tenants` command lists each tenant that the queue tracks. For each
tenant, the command shows the tenant's CPU usage in MHz and memory usage in MB
next to the total usage of all tenants, and the tenant's percentage of the total
usage. Usage values decay over time according to the queue's `half_life`
parameter. Refer to [Tenant usage and
decay](/nomad/docs/concepts/scheduling/batch-job-queue#tenant-usage-and-decay)
for details.

The command reports tenants for dynamic priority queues only.

When ACLs are enabled, this command requires a token with `operator:read`
permissions.

## Options

- `-node-pool`: The node pool whose queue to inspect. Defaults to `default`.

- `-json`: Output the tenants in JSON format.

## Examples

List the tenants in the dynamic priority queue of the `batch` node pool.

```shell-session
$ nomad queue tenants -node-pool batch
Batch Queue Tenants
Tenant  Resource  Usage / Total    Percentage
team-a                             100
        cpu       598.73 / 598.73
        memory    255.46 / 255.46
team-b                             0
        cpu       0.00 / 598.73
        memory    0.00 / 255.46
```

List the tenants in JSON format.

```shell-session
$ nomad queue tenants -node-pool batch -json
[{"PercentageUsed":100,"TenantID":"team-a","TenantUsage":{"cpu":598.7308083750042,"memory":255.4584782400018},"TotalUsage":{"cpu":598.7308083750042,"memory":255.4584782400018}},{"PercentageUsed":0,"TenantID":"team-b","TenantUsage":{"cpu":0,"memory":0},"TotalUsage":{"cpu":598.7308083750042,"memory":255.4584782400018}}]
```
