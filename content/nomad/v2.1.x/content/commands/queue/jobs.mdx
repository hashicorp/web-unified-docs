# `nomad queue jobs` command reference

The `queue jobs` command lists the jobs in the batch job queue of a node pool.

## Usage

```plaintext
nomad queue jobs [options]
```

The `queue jobs` command lists each job that is waiting in the queue or that the
queue sent to the scheduler. Nomad removes a job from the list after it places
the job's allocations.

The output depends on the queue type.

- For a FIFO queue, the command lists each job's ID, status, position, and
  creation time.
- For a dynamic priority queue, the command also lists each job's tenant, its
  adjusted priority, its base priority, and the usage, age, CPU, and memory
  adjustments that make up its adjusted priority.

The `Status` column shows `queued` for a job that is waiting in the queue,
`placing` for a job that the queue sent to the scheduler, and `blocked` with a
reason for a job that the scheduler cannot place because of its constraints.
The job at position `0` is the job that the queue sent to the scheduler.

When the node pool does not have a batch job queue, the command returns `No batch
job queue configured for node pool: <node_pool>`.

When ACLs are enabled, this command requires a token with the `list-jobs`
capability. The command only lists jobs in namespaces where the token has the
`list-jobs` capability.

## Options

- `-node-pool`: The node pool whose queue to list. Defaults to `default`.

- `-p`: List jobs in queue order, which is the order that the queue sends them
  to the scheduler. Without this flag, the command sorts jobs by job ID.

- `-per-page`: The maximum number of jobs to return per page. When not set, or
  set to `0`, the command returns all jobs.

- `-page-token`: The pagination token from a previous page of results, which
  specifies where to start the next page.

- `-json`: Output the jobs in JSON format.

## Examples

List the jobs in the FIFO queue of the `batch` node pool.

```shell-session
$ nomad queue jobs -node-pool batch
Batch Queue Workloads
JobID    Status   Position  CreatedAt
bravo    placing  0         2026-09-25T10:44:38-05:00
charlie  queued   1         2026-09-25T10:44:39-05:00
```

List the jobs in the dynamic priority queue of the `batch` node pool in queue
order.

```shell-session
$ nomad queue jobs -node-pool batch -p
Batch Queue Workloads
JobID        Tenant  Status   Adjusted Priority  Base Priority  Position  Usage  Age  Cpu  Memory  CreatedAt
team-a-job2  team-a  placing  61                 50             0         0      0    4    7       2026-09-25T10:45:40-05:00
team-b-job1  team-b  queued   111                50             1         50     0    4    7       2026-09-25T10:45:40-05:00
team-b-job2  team-b  queued   111                50             2         50     0    4    7       2026-09-25T10:45:40-05:00
team-b-job3  team-b  queued   111                50             3         50     0    4    7       2026-09-25T10:45:41-05:00
team-a-job3  team-a  queued   61                 50             4         0      0    4    7       2026-09-25T10:45:40-05:00
```

List the first two jobs in queue order, and then list the next page.

```shell-session
$ nomad queue jobs -node-pool batch -p -per-page 2
Batch Queue Workloads
JobID        Tenant  Status   Adjusted Priority  Base Priority  Position  Usage  Age  Cpu  Memory  CreatedAt
team-b-job1  team-b  placing  111                50             0         50     0    4    7       2026-09-25T10:46:00-05:00
team-b-job2  team-b  queued   111                50             1         50     0    4    7       2026-09-25T10:45:40-05:00

Results have been paginated. To get the next page run:

nomad queue jobs -node-pool batch -p -per-page 2 -page-token 56.team-b-job3
```

List the jobs in JSON format.

```shell-session
$ nomad queue jobs -node-pool batch -json
[{"JobID":"bravo","Position":0,"Status":"placing","CreatedAt":1790351078401869000},{"JobID":"charlie","Position":1,"Status":"queued","CreatedAt":1790351079666458000}]
```
