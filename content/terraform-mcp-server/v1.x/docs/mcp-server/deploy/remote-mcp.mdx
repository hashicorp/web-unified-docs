# Connect to the Remote Terraform MCP server

<Note>

This feature is in beta. Do not use beta functionality in production environments.

</Note>

This topic describes how to connect your AI client to the Remote Terraform Model Context Protocol (MCP) server, which HashiCorp hosts and manages at `https://mcp.terraform.io/mcp`. You authenticate with an HCP Terraform API token so that your AI model can access the public Terraform registry, your private registry, and your HCP Terraform organizations. You do not need to install Docker, run a binary, or operate a server.

## Background

The Remote Terraform MCP server runs the same Terraform MCP server that you can [deploy locally](/terraform/mcp-server/deploy/local) or [self-host](/terraform/mcp-server/deploy/self-hosted). The Remote Terraform MCP server differs from those deployments in the following ways:

- HashiCorp operates, updates, and scales the server.
- The server connects only to HCP Terraform. It does not support Terraform Enterprise. To use the Terraform MCP server with Terraform Enterprise, refer to [Deploy a self-hosted Terraform MCP server](/terraform/mcp-server/deploy/self-hosted).
- The server authenticates every request with the API token that your client sends. The server can only perform actions that your token has permission to perform.

Refer to [Deploy the Terraform MCP server](/terraform/mcp-server/deploy) for a comparison of the deployment options.

## Requirements

You must have the following to connect to the Remote Terraform MCP server:

- An HCP Terraform account.
- An HCP Terraform API token. We recommend using a user API token. Refer to [Create an API token](#create-an-api-token) for more information.
- An AI client that supports MCP servers over HTTP and lets you send a custom HTTP header with each request.
- Network access to `https://mcp.terraform.io` from the machine that runs your AI client.

## Create an API token

We recommend authenticating with an HCP Terraform user API token. A user API token authenticates as you, so your AI model can access every organization that your account belongs to, with the same permissions that you have.

1. Create a user API token. Refer to [User API tokens](/terraform/cloud-docs/users-teams-organizations/api-tokens#user-api-tokens) for instructions.
1. Copy the token. HCP Terraform only displays the token once.
1. Store the token securely. Do not commit a configuration file that contains your token to version control.

If you cannot use a user API token, you can use a team API token instead. Refer to [Team API tokens](/terraform/cloud-docs/users-teams-organizations/api-tokens#team-api-tokens) for instructions.

<Warning>

A user API token can reach every HCP Terraform organization that your account belongs to. Before you ask your AI model to perform write, plan, apply, or state operations, confirm which organization the model is targeting. During the beta, we recommend creating a token for an account that can only access non-production organizations.

</Warning>

## Configure your AI client

Add the Remote Terraform MCP server URL and an `Authorization` header that contains your API token to your AI client's MCP configuration. Replace `<YOUR_HCP_TERRAFORM_TOKEN>` with the token that you created.

<Tabs>

<Tab heading="OpenCode">

Add the following configuration to your `opencode.json` file:

```json
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "terraform": {
      "type": "remote",
      "url": "https://mcp.terraform.io/mcp",
      "enabled": true,
      "headers": {
        "Authorization": "Bearer <YOUR_HCP_TERRAFORM_TOKEN>"
      }
    }
  }
}
```

</Tab>

<Tab heading="IBM Bob">

Add the following configuration to your `.bob/mcp.json` file:

```json
{
  "mcpServers": {
    "terraform": {
      "url": "https://mcp.terraform.io/mcp",
      "headers": {
        "Authorization": "Bearer <YOUR_HCP_TERRAFORM_TOKEN>"
      }
    }
  }
}
```

</Tab>

</Tabs>

For other AI clients, add a remote MCP server that uses `https://mcp.terraform.io/mcp` as the URL and sends the `Authorization: Bearer <YOUR_HCP_TERRAFORM_TOKEN>` header. Refer to your AI client's documentation for the configuration format.

After you update the configuration, restart or reload your AI client so that it connects to the `terraform` server.

### Verify the connection

Ask your AI model which HCP Terraform user it is authenticated as. The model uses the `whoami` tool to return the username and email address associated with your token. Refer to the [tools reference](/terraform/mcp-server/reference#available-tools) for more information.

### How the server reads your token

The Remote Terraform MCP server reads your token from the `Authorization` bearer header. The server also accepts the token in a `TFE_TOKEN` header, but the `Authorization` header takes precedence when a request includes both.

The server rejects the following requests:

- Requests that pass the token in a query parameter.
- Requests that specify a Terraform address in a header or query parameter. The Remote Terraform MCP server always connects to HCP Terraform.

## Available tools

The Remote Terraform MCP server provides the tools in the `registry`, `registry-private`, and `terraform` toolsets. Every tool runs with the permissions of the token that your client sends. Refer to the [tools reference](/terraform/mcp-server/reference#available-tools) for a description of each tool.

## Limitations

The Remote Terraform MCP server has the following limitations:

- The server does not support Terraform Enterprise.
- HCP Terraform does not act as an OAuth provider, so you must add an API token to your client configuration.
- You cannot change the server configuration, such as the enabled toolsets or environment variables. To control the server configuration, [deploy a self-hosted server](/terraform/mcp-server/deploy/self-hosted).
- The server applies rate limits to protect HCP Terraform and the Terraform registry from excessive requests.

## Security

The Remote Terraform MCP server does not store or log your token. The server uses the token only for the duration of a request to call HCP Terraform and private registry APIs. Refer to [Remote Terraform MCP server security](/terraform/mcp-server/security#remote-terraform-mcp-server-security) for more information.

The server generates outputs and recommendations dynamically. Always review changes before you apply them to your infrastructure.
