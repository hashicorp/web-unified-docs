# View policy enforcement results for Stacks

<Badge text="Beta" />

When you add [policy sets](/terraform/cloud-docs/policy-enforcement/manage-policy-sets) to a Stack, HCP Terraform enforces those policy sets on every deployment run. HCP Terraform displays the policy enforcement results in the UI for each run. Depending on each policy's [enforcement level](/terraform/cloud-docs/policy-enforcement/manage-policy-sets#policy-enforcement-levels), policy failures can also stop the deployment and prevent Terraform from provisioning infrastructure.

Stacks currently supports [Terraform policy](/terraform/cloud-docs/policy-enforcement/define-policies/terraform-policy) only. Support for Sentinel and OPA is not available for Stacks.

## Policy Evaluation in Stack Deployments

HCP Terraform only evaluates policies for successful plans. For Stacks, Terraform policy evaluations can occur only at plan time. HCP Terraform will not evaluate policies on Stacks at setup time or after the apply phase is complete.

Refer to [Stack Runs](/terraform/cloud-docs/stacks/runs) for more details about Stack deployment stages.

## View Policy Results

To view the policy results for a Stack deployment:
1. Go to your Stack and navigate to the **Runs** page.
1. Click a deployment run to view its details.

HCP Terraform displays a timeline of the deployment's events. Click a policy evaluation event to view policy results and details about any failed policies.

### Terraform policy enforcement levels

When policies with an `advisory` enforcement level fail, HCP Terraform will notify the user in the deployment run results and continue the deployment.

When policies with a `mandatory_overridable` or `mandatory` enforcement levels fail, HCP Terraform will halt the deployment. You cannot override `mandatory_overridable` failures in Stacks.
