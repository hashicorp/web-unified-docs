# Terraform Developer Portal API reference

Use the Terraform Developer Portal API endpoints to manage templates, applications, and add-ons. Refer to the [What is Terraform Developer Portal](/terraform/cloud-docs/developer-portal) for more information.

## API Categories

The Terraform Developer Portal API manages the following resources

### Templates

Templates define reusable infrastructure patterns that developers can use to create applications. Platform teams manage templates at the organization level.

Refer to [Templates API reference](/terraform/cloud-docs/api-docs/developer-portal/templates) for endpoint documentation. Refer to [Create and manage templates](/terraform/cloud-docs/developer-portal/template-create) to learn more about templates in Terraform Developer Portal.

### Applications

Applications are running instances of templates in projects, each with its own HCP Terraform workspace. Developers create applications from templates and manage them within their HCP Terraform projects.

Refer to [Applications API reference](/terraform/cloud-docs/api-docs/developer-portal/applications) for endpoint documentation. Refer to [Deploy and manage applications](/terraform/cloud-docs/developer-portal/template-use) to learn more about applications in Terraform Developer Portal.

### Add-Ons

Add-ons provision additional infrastructure resources to extend application functionality. Platform teams define add-on definition at the organization level, and developers install them into applications.

Refer to [Add-Ons API reference](/terraform/cloud-docs/api-docs/developer-portal/add-ons) for endpoint documentation. Refer to [Create and manage add-on definitions](/terraform/cloud-docs/developer-portal/addon-create) and [Install and manage add-ons ](/terraform/cloud-docs/developer-portal/addon-use) to learn more about add-ons in Terraform Developer Portal.

## Permissions

You must meet the following requirements to use this API endpoint:

- You must have organization-level permissions to manage templates and add-on definitions.
- You must have project-level permissions to create and manage applications and add-ons within a project.
- All endpoints require authentication using a valid API token.

## Query parameters

The following query parameters are available on list and get endpoints:

| Parameter | Type | Description |
| --- | --- | --- |
| `page[number]` | integer | Page number to retrieve (list endpoints only) |
| `page[size]` | integer | Items per page; defaults to 20 (list endpoints only) |
| `fields[<type>]` | string | Comma-separated list of fields to return. Use underscores for dashed attribute names (e.g., `module_source`). An empty value returns no fields. |
