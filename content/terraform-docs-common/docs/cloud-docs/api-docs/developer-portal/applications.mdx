# Terraform Developer Portal applications API reference

Applications are running instances of templates within projects, each with its own HCP Terraform workspace.

## Overview

This topic describes how to use the following endpoints to manage applications using the API:

| Method | Endpoint | Description |
| --- | --- | --- |
| `GET` | `/dev-portal/organizations/:organization_name/applications` | [Search for applications across all projects in an organization](#list-all-applications) |
| `GET` | `/dev-portal/organizations/:organization_name/projects/:project_id/applications` | [List all applications in a project](#list-all-applications-in-a-project) |
| `GET` | `/dev-portal/organizations/:organization_name/applications/:application_id` | [Retrieve details of an application](#show-an-application) |
| `GET` | `/dev-portal/organizations/:organization_name/projects/:project_id/applications/:application_id` | [Retrieve details of an application in a project](#show-an-application-in-a-project) |
| `POST` | `/dev-portal/organizations/:organization_name/projects/:project_id/applications` | [Create a new application from a template](#create-an-application) |
| `PATCH` | `/dev-portal/organizations/:organization_name/projects/:project_id/applications/:application_id` | [Update an existing application](#update-an-application) |
| `DELETE` | `/dev-portal/organizations/:organization_name/projects/:project_id/applications/:application_id` | [Delete an application](#delete-an-application) |

## List all applications

Use the following endpoint to search for applications across all projects in an organization:

`GET /dev-portal/organizations/:organization_name/applications`

| Parameter | Description |
| --- | --- |
| `:organization_name` | The name of the organization. |

Returns all applications across every project in the organization.

| Status | Response | Reason |
| --- | --- | --- |
| [200][] | [JSON API document][] (`type: "tdp-applications"`) | Success |
| [404][] | [JSON API error object][] | Organization not found or user not authorized |

### Query Parameters

This endpoint supports pagination [with standard URL query parameters](/terraform/cloud-docs/api-docs#query-parameters). Remember to percent-encode `[` as `%5B` and `]` as `%5D` if your tooling doesn't automatically encode URLs.

| Parameter | Description |
| --- | --- |
| `page[number]` | **Optional.** If omitted, the endpoint returns the first page. Page numbers are 1-indexed and can only be integers. |
| `page[size]` | **Optional.** If omitted, the endpoint returns 20 items per page. Page size can be between 1 and 100. |
| `fields[tdp-applications]` | **Optional.** Comma-separated list of fields to return. Use underscores for dashed attribute names. An empty value returns no fields. |

### Sample Request

```shell
curl \
  --header "Authorization: Bearer $TOKEN" \
  --header "Content-Type: application/vnd.api+json" \
  https://app.terraform.io/api/v2/dev-portal/organizations/my-organization/applications
```

## Create an application

Use the following endpoint to create a new application in a project from a template:

`POST /dev-portal/organizations/:organization_name/projects/:project_id/applications`

| Parameter | Description |
| --- | --- |
| `:organization_name` | The name of the organization. |
| `:project_id` | The project ID. |

Creates a new application in the project from a template.

| Status | Response | Reason |
| --- | --- | --- |
| [201][] | [JSON API document][] (`type: "tdp-applications"`) | Successfully created |
| [404][] | [JSON API error object][] | Project or template not found, or user not authorized |

### Request Body

This POST endpoint requires a JSON object with the following properties as a request payload.

Properties without a default value are required.

| Key path | Type | Default | Description |
| --- | --- | --- | --- |
| `data.type` | string | | Must be `"tdp-applications"`. |
| `data.attributes.name` | string | | **Required.** Application name (1-50 characters). Also usable as `{application_id}` in other endpoints. |
| `data.attributes.template-name` | string | | **Required.** Name of the template to create from. |
| `data.attributes.readme` | string | `""` | Raw, user-authored readme. |
| `data.attributes.tags` | array | `[]` | Tags for categorization. |
| `data.attributes.input-variables` | array | | List of values for the template's variables. |
| `data.attributes.input-variables[].variable-name` | string | | The name of the variable from the template. |
| `data.attributes.input-variables[].variable-type` | string | | The data type for the variable (for example, "string", "number", "boolean"). |
| `data.attributes.input-variables[].value` | any | | The value to set for this variable. |

### Sample Payload

```json
{
  "data": {
    "type": "tdp-applications",
    "attributes": {
      "name": "checkout-api",
      "template-name": "web-service",
      "readme": "Owned by payments team.",
      "tags": ["payments", "prod"],
      "input-variables": [
        {
          "variable-name": "instance_size",
          "variable-type": "string",
          "value": "medium"
        }
      ]
    }
  }
}
```

### Sample Request

```shell
curl \
  --header "Authorization: Bearer $TOKEN" \
  --header "Content-Type: application/vnd.api+json" \
  --request POST \
  --data @payload.json \
  https://app.terraform.io/api/v2/dev-portal/organizations/my-organization/projects/prj-abc789/applications
```

## Update an application

Use the following endpoint to update an existing application. Only the attributes you include in the request body will be modified:

`PATCH /dev-portal/organizations/:organization_name/projects/:project_id/applications/:application_id`

| Parameter | Description |
| --- | --- |
| `:organization_name` | The name of the organization. |
| `:project_id` | The project ID. |
| `:application_id` | The application ID or name. |

Updates an existing application. Only the attributes you include in the request body will be modified.

| Status | Response | Reason |
| --- | --- | --- |
| [200][] | [JSON API document][] (`type: "tdp-applications"`) | Successfully updated |
| [404][] | [JSON API error object][] | Application not found or user not authorized |

### Request Body

This PATCH endpoint requires a JSON object with the following properties as a request payload.

| Key path | Type | Default | Description |
| --- | --- | --- | --- |
| `data.type` | string | | Must be `"tdp-applications"`. |
| `data.id` | string | | The application ID. |
| `data.attributes` | object | | Object containing the attributes to update. |

### Sample Payload

```json
{

    "id": "app-def456",

    "attributes": {
      "readme": "Owned by payments team. On-call: #payments-oncall",
      "tags": ["payments", "prod", "tier-1"]

  }
}
```

### Sample Request

```shell
curl \
  --header "Authorization: Bearer $TOKEN" \
```
