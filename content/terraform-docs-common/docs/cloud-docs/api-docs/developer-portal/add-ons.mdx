# Terraform Developer Portal add-ons API reference

Add-ons extend application functionality by provisioning additional infrastructure resources. Platform teams define add-ons at the organization level, and developers install them into applications within projects.

## Overview

This topic describes how to use the following endpoints to manage add-on definitions and add-ons using the API:

### Add-On Definitions

| Method | Endpoint | Description |
| --- | --- | --- |
| `GET` | `/dev-portal/organizations/:organization_name/addon-definitions` | [List all add-on definitions in an organization](#list-add-on-definitions) |
| `POST` | `/dev-portal/organizations/:organization_name/addon-definitions` | [Create a new add-on definition](#create-an-add-on-definition) |
| `GET` | `/dev-portal/organizations/:organization_name/addon-definitions/:add_on_definition_id` | [Retrieve details of a specific add-on definition](#show-an-add-on-definition) |
| `PATCH` | `/dev-portal/organizations/:organization_name/addon-definitions/:add_on_definition_id` | [Update an existing add-on definition](#update-an-add-on-definition) |
| `DELETE` | `/dev-portal/organizations/:organization_name/addon-definitions/:add_on_definition_id` | [Delete an add-on definition](#delete-an-add-on-definition) |

### Add-Ons

| Method | Endpoint | Description |
| --- | --- | --- |
| `GET` | `/dev-portal/organizations/:organization_name/projects/:project_id/add-ons` | [List all add-ons in a project](#list-installed-add-ons-in-a-project) |
| `GET` | `/dev-portal/organizations/:organization_name/projects/:project_id/applications/:application_id/add-ons` | [List all add-ons in an application](#list-installed-add-ons-in-an-application) |
| `POST` | `/dev-portal/organizations/:organization_name/projects/:project_id/applications/:application_id/add-ons` | [Install an add-on into an application](#install-an-add-on) |
| `GET` | `/dev-portal/organizations/:organization_name/projects/:project_id/add-ons/:add_on_id` | [Retrieve details of a specific add-on](#show-an-installed-add-on) |
| `PATCH` | `/dev-portal/organizations/:organization_name/projects/:project_id/add-ons/:add_on_id` | [Update an existing add-on](#update-an-installed-add-on) |
| `DELETE` | `/dev-portal/organizations/:organization_name/projects/:project_id/add-ons/:add_on_id` | [Delete an add-on](#delete-an-installed-add-on) |

## List add-on definitions

Use the following endpoint to list all add-on definitions in an organization:

`GET /dev-portal/organizations/:organization_name/addon-definitions`

| Parameter | Description |
| --- | --- |
| `:organization_name` | The name of the organization. |

Lists all add-on definitions in the organization.

| Status | Response | Reason |
| --- | --- | --- |
| [200][] | [JSON API document][] (`type: "tdp-addon-definitions"`) | Success |
| [404][] | [JSON API error object][] | Organization not found or user not authorized |

### Query Parameters

This endpoint supports pagination [with standard URL query parameters](/terraform/cloud-docs/api-docs#query-parameters). Remember to percent-encode `[` as `%5B` and `]` as `%5D` if your tooling doesn't automatically encode URLs.

| Parameter | Description |
| --- | --- |
| `page[number]` | **Optional.** If omitted, the endpoint returns the first page. Page numbers are 1-indexed and can only be integers. |
| `page[size]` | **Optional.** If omitted, the endpoint returns 20 items per page. Page size can be between 1 and 100. |
| `fields[tdp-addon-definitions]` | **Optional.** Comma-separated list of fields to return. Use underscores for dashed attribute names. An empty value returns no fields. |

### Sample Request

```shell
curl \
  --header "Authorization: Bearer $TOKEN" \
  --header "Content-Type: application/vnd.api+json" \
  https://app.terraform.io/api/v2/dev-portal/organizations/my-organization/addon-definitions
```

## Create an add-on definition

Use the following endpoint to create a new add-on definition in an organization:

`POST /dev-portal/organizations/:organization_name/addon-definitions`

| Parameter | Description |
| --- | --- |
| `:organization_name` | The name of the organization. |

Creates a new add-on definition in the organization.

| Status | Response | Reason |
| --- | --- | --- |
| [201][] | [JSON API document][] (`type: "tdp-addon-definitions"`) | Successfully created |
| [404][] | [JSON API error object][] | Organization not found or user not authorized |

### Request Body

This POST endpoint requires a JSON object with the following properties as a request payload.

Properties without a default value are required.

| Key path | Type | Default | Description |
| --- | --- | --- | --- |
| `data.type` | string | | Must be `"tdp-addon-definitions"`. |
| `data.attributes.name` | string | | Definition name (1-50 characters).|
| `data.attributes.summary` | string | | One-line summary of what it provisions. |
| `data.attributes.description` | string | | Longer description and intended use. |
| `data.attributes.module-source` | string | | Terraform registry source address of the backing module. |
| `data.attributes.module-id` | string | | No-code ID of the backing module (for example, `nocode-abcdefghijklmnop`). |
| `data.attributes.variable-options` | array | | List of input variables exposed to users installing an add-on. |
| `data.attributes.variable-options[].variable-name` | string | | The name of the variable. |
| `data.attributes.variable-options[].variable-type` | string | | The data type for the variable (for example, "string", "number", "boolean"). |
| `data.attributes.variable-options[].description` | string | | Description of the variable. |
| `data.attributes.variable-options[].user-editable` | boolean | | Whether users can modify this variable when installing an add-on. |
| `data.attributes.variable-options[].options` | array | | List of allowed values for the variable. |
| `data.attributes.readme-template` | string | | Markdown template used to generate each add-on's readme. |

### Sample Payload

```json
{
  "data": {
    "type": "tdp-addon-definitions",
    "attributes": {
      "name": "postgres",
      "summary": "Managed PostgreSQL database",
      "description": "RDS Postgres with backups and IAM auth.",
      "module-source": "app.terraform.io/my-organization/postgres/aws",
      "module-id": "nocode-pqr456",
      "variable-options": [
        {
          "variable-name": "engine_version",
          "variable-type": "string",
          "description": "Postgres major version",
          "user-editable": true,
          "options": ["15", "16"]
        }
      ],
      "readme-template": "# Managed PostgreSQL instance.\n\n{{.ApplicationName}} database",
    }
  }
}
```

### Sample Request

```shell
curl \
  --header "Authorization: Bearer $TOKEN" \
  --header "Content-Type: application/vnd.api+json" \
  --request POST \
  --data @payload.json \
  https://app.terraform.io/api/v2/dev-portal/organizations/my-organization/addon-definitions
```

### Sample Response


## Install an add-on

Use the following endpoint to install an add-on into an application from an add-on definition:

`POST /dev-portal/organizations/:organization_name/projects/:project_id/applications/:application_id/add-ons`

| Parameter | Description |
| --- | --- |
| `:organization_name` | The name of the organization. |
| `:project_id` | The project ID. |
| `:application_id` | The application ID or name. |

Installs an add-on into the application from an add-on definition.

| Status | Response | Reason |
| --- | --- | --- |
| [201][] | [JSON API document][] (`type: "tdp-addons"`) | Successfully created |
| [404][] | [JSON API error object][] | Application or add-on definition not found, or user not authorized |

### Request Body

This POST endpoint requires a JSON object with the following properties as a request payload.

Properties without a default value are required.

| Key path | Type | Default | Description |
| --- | --- | --- | --- |
| `data.type` | string | | Must be `"tdp-addons"`. |
| `data.attributes.name` | string | | Name for the add-on installation. Must be unique. |
| `data.attributes.readme` | string | | User-authored readme. |
| `data.attributes.tags` | array | | Tags for categorization. |
| `data.attributes.input-variables` | array | `[]` | List of values for the definition's variables. |
