# Terraform Developer Portal templates API reference

Templates define reusable infrastructure patterns that developers can use to create applications. Platform teams manage templates at the organization level.

## Overview

This topic describes how to use the following endpoints to manage templates using the API:

| Method | Endpoint | Description |
| --- | --- | --- |
| `GET` | `/dev-portal/organizations/:organization_name/templates` | [List all templates in an organization](#list-templates) |
| `POST` | `/dev-portal/organizations/:organization_name/templates` | [Create a new template](#create-a-template) |
| `GET` | `/dev-portal/organizations/:organization_name/templates/:template_id` | [Retrieve details of a specific template](#show-a-template) |
| `PATCH` | `/dev-portal/organizations/:organization_name/templates/:template_id` | [Update an existing template](#update-a-template) |
| `DELETE` | `/dev-portal/organizations/:organization_name/templates/:template_id` | [Delete a template](#delete-a-template) |

## List templates

Use the following endpoint to list all templates in an organization:

`GET /dev-portal/organizations/:organization_name/templates`

| Parameter | Description |
| --- | --- |
| `:organization_name` | The name of the organization. |

| Status | Response | Reason |
| --- | --- | --- |
| [200][] | [JSON API document][] (`type: "tdp-templates"`) | Success |
| [404][] | [JSON API error object][] | Organization not found or user not authorized |

### Query Parameters

This endpoint supports pagination [with standard URL query parameters](/terraform/cloud-docs/api-docs#query-parameters). Remember to percent-encode `[` as `%5B` and `]` as `%5D` if your tooling doesn't automatically encode URLs.

| Parameter | Description |
| --- | --- |
| `page[number]` | **Optional.** If omitted, the endpoint returns the first page. Page numbers are 1-indexed and can only be integers. |
| `page[size]` | **Optional.** If omitted, the endpoint returns 20 items per page. Page size can be between 1 and 100. |
| `fields[tdp-templates]` | **Optional.** Comma-separated list of fields to return. Use underscores for dashed attribute names. An empty value returns no fields. |

### Sample Request

```shell
curl \
  --header "Authorization: Bearer $TOKEN" \
  --header "Content-Type: application/vnd.api+json" \
  https://app.terraform.io/api/v2/dev-portal/organizations/my-organization/templates
```

## Create a template

Use the following endpoint to create a new template in an organization:

`POST /dev-portal/organizations/:organization_name/templates`

| Parameter | Description |
| --- | --- |
| `:organization_name` | The name of the organization. |

| Status | Response | Reason |
| --- | --- | --- |
| [201][] | [JSON API document][] (`type: "tdp-templates"`) | Successfully created |
| [404][] | [JSON API error object][] | Organization not found or user not authorized |

### Request Body

This POST endpoint requires a JSON object with the following properties as a request payload.

Properties without a default value are required.

| Key path | Type | Default | Description |
| --- | --- | --- | --- |
| `data.type` | string | | Must be `"tdp-templates"`. |
| `data.attributes.name` | string | | Template name (1-50 characters). Also usable as `{template_id}` in other endpoints. |
| `data.attributes.summary` | string | | One-line summary of what the template provisions. |
| `data.attributes.description` | string | `""` | Longer description and intended use. |
| `data.attributes.module-source` | string | | Terraform registry source address of the backing module. |
| `data.attributes.module-id` | string | | No-code ID of the backing module (for example, `nocode-abcdefghijklmnop`). |
| `data.attributes.variable-options` | array | `[]` | List of input variables exposed to users creating an application. |
| `data.attributes.variable-options[].variable-name` | string | | The name of the variable. |
| `data.attributes.variable-options[].variable-type` | string | | The data type for the variable (for example, "string", "number", "boolean"). |
| `data.attributes.variable-options[].description` | string | | Description of the variable. |
| `data.attributes.variable-options[].user-editable` | boolean | | Whether users can modify this variable when creating an application. |
| `data.attributes.variable-options[].options` | array | | List of allowed values for the variable. |
| `data.attributes.readme-template` | string | `""` | Markdown template used to generate each application's readme. |

### Sample Payload

```json
{
  "data": {
    "type": "tdp-templates",
    "attributes": {
      "name": "web-service",
      "summary": "Containerized web service with load balancer",
      "description": "Standard pattern for stateless HTTP services.",
      "module-source": "app.terraform.io/my-organization/web-service/aws",
      "module-id": "nocode-abcdefghijklmnop",
      "variable-options": [
        {
          "variable-name": "instance_size",
          "variable-type": "string",
          "description": "Compute size",
          "user-editable": true,
          "options": ["small", "medium", "large"]
        }
      ],
      "readme-template": "# Web Service\n\n{{.ApplicationName}} is deployed from web-service template."
    }
  }
}
```

### Sample Request

```shell
curl \
  --header "Authorization: Bearer $TOKEN" \
  --header "Content-Type: application/vnd.api+json" \
  --request POST \
  --data @payload.json \
  https://app.terraform.io/api/v2/dev-portal/organizations/my-organization/templates
```

### Sample Response

## Update a template

Use the following endpoint to update an existing template. Only the attributes you include in the request body will be modified:

`PATCH /dev-portal/organizations/:organization_name/templates/:template_id`

| Parameter | Description |
| --- | --- |
| `:organization_name` | The name of the organization. |
| `:template_id` | The template ID or name. |

| Status | Response | Reason |
| --- | --- | --- |
| [200][] | [JSON API document][] (`type: "tdp-templates"`) | Successfully updated |
| [404][] | [JSON API error object][] | Template not found or user not authorized |

### Request Body

This PATCH endpoint requires a JSON object with the following properties as a request payload.

| Key path | Type | Default | Description |
| --- | --- | --- | --- |
| `data.type` | string | | Must be `"tdp-templates"`. |
| `data.id` | string | | The template ID. |
| `data.attributes` | object | | Object containing the attributes to update. |

### Sample Payload

```json
{
  "data": {
    "id": "tmpl-abc123",
    "type": "tdp-templates",
    "attributes": {
      "summary": "Web service with ALB and autoscaling",
      "description": "Updated pattern with enhanced scaling capabilities."
    }
  }
}
```

### Sample Request

```shell
curl \
  --header "Authorization: Bearer $TOKEN" \
  --header "Content-Type: application/vnd.api+json" \
  --request PATCH \
  --data @payload.json \
  https://app.terraform.io/api/v2/dev-portal/organizations/my-organization/templates/web-service
```

## Delete a template

Use the following endpoint to delete a template from the organization.

`DELETE /dev-portal/organizations/:organization_name/templates/:template_id`

| Parameter | Description |
| --- | --- |
| `:organization_name` | The name of the organization. |
| `:template_id` | The template ID or name. |

| Status | Response | Reason |
| --- | --- | --- |
| [204][] | No Content | Successfully deleted |
| [404][] | [JSON API error object][] | Template not found or user not authorized |

### Sample Request

```shell
curl \
  --header "Authorization: Bearer $TOKEN" \
  --header "Content-Type: application/vnd.api+json" \
  --request DELETE \
  https://app.terraform.io/api/v2/dev-portal/organizations/my-organization/templates/web-service
```
