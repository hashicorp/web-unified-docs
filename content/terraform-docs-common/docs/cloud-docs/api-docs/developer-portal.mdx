# Developer Portal API

The Developer Portal API allows platform teams to publish templates and add-on definitions at the organization level, and enables developers to create applications and install add-ons within projects.

## Overview

The scope of the API includes the following endpoints:

| Method | Path | Action |
| --- | --- | --- |
| `GET` | `/dev-portal/organizations/:organization_name/templates` | Call this endpoint to [list templates](#list-templates). |
| `POST` | `/dev-portal/organizations/:organization_name/templates` | Call this endpoint to [create a template](#create-a-template). |
| `GET` | `/dev-portal/organizations/:organization_name/templates/:template_id` | Call this endpoint to [show a template](#show-a-template). |
| `PATCH` | `/dev-portal/organizations/:organization_name/templates/:template_id` | Call this endpoint to [update a template](#update-a-template). |
| `DELETE` | `/dev-portal/organizations/:organization_name/templates/:template_id` | Call this endpoint to [delete a template](#delete-a-template). |
| `GET` | `/dev-portal/organizations/:organization_name/applications` | Call this endpoint to [search applications organization-wide](#search-applications-organization-wide). |
| `GET` | `/dev-portal/organizations/:organization_name/applications/:application_id` | Call this endpoint to [show an application](#show-an-application-organization-scoped) without requiring a project ID. |
| `GET` | `/dev-portal/organizations/:organization_name/projects/:project_id/applications` | Call this endpoint to [list applications in a project](#list-applications-in-a-project). |
| `POST` | `/dev-portal/organizations/:organization_name/projects/:project_id/applications` | Call this endpoint to [create an application](#create-an-application). |
| `GET` | `/dev-portal/organizations/:organization_name/projects/:project_id/applications/:application_id` | Call this endpoint to [show an application](#show-an-application). |
| `PATCH` | `/dev-portal/organizations/:organization_name/projects/:project_id/applications/:application_id` | Call this endpoint to [update an application](#update-an-application). |
| `DELETE` | `/dev-portal/organizations/:organization_name/projects/:project_id/applications/:application_id` | Call this endpoint to [delete an application](#delete-an-application). |
| `GET` | `/dev-portal/organizations/:organization_name/addon-definitions` | Call this endpoint to [list add-on definitions](#list-add-on-definitions). |
| `POST` | `/dev-portal/organizations/:organization_name/addon-definitions` | Call this endpoint to [create an add-on definition](#create-an-add-on-definition). |
| `GET` | `/dev-portal/organizations/:organization_name/addon-definitions/:add_on_definition_id` | Call this endpoint to [show an add-on definition](#show-an-add-on-definition). |
| `PATCH` | `/dev-portal/organizations/:organization_name/addon-definitions/:add_on_definition_id` | Call this endpoint to [update an add-on definition](#update-an-add-on-definition). |
| `DELETE` | `/dev-portal/organizations/:organization_name/addon-definitions/:add_on_definition_id` | Call this endpoint to [delete an add-on definition](#delete-an-add-on-definition). |
| `GET` | `/dev-portal/organizations/:organization_name/projects/:project_id/add-ons` | Call this endpoint to [list add-ons in a project](#list-add-ons-in-a-project). |
| `GET` | `/dev-portal/organizations/:organization_name/projects/:project_id/applications/:application_id/add-ons` | Call this endpoint to [list add-ons in an application](#list-add-ons-in-an-application). |
| `POST` | `/dev-portal/organizations/:organization_name/projects/:project_id/applications/:application_id/add-ons` | Call this endpoint to [install an add-on](#install-an-add-on). |
| `GET` | `/dev-portal/organizations/:organization_name/projects/:project_id/add-ons/:add_on_id` | Call this endpoint to [show an add-on](#show-an-add-on). |
| `PATCH` | `/dev-portal/organizations/:organization_name/projects/:project_id/add-ons/:add_on_id` | Call this endpoint to [update an add-on](#update-an-add-on). |
| `DELETE` | `/dev-portal/organizations/:organization_name/projects/:project_id/add-ons/:add_on_id` | Call this endpoint to [delete an add-on](#delete-an-add-on). |

## Requirements

You must meet the following requirements to use this API endpoint:

- You must have organization-level permissions to manage templates and add-on definitions.
- You must have project-level permissions to create and manage applications and add-ons within a project.
- All endpoints require authentication using a valid API token.

Refer to [Developer Portal](/terraform/cloud-docs/developer-portal) for additional information about using Terraform Developer Portal.

## Query parameters

The following query parameters are available on list and get endpoints:

| Parameter | Type | Description |
| --- | --- | --- |
| `page[number]` | integer | Page number to retrieve (list endpoints only) |
| `page[size]` | integer | Items per page; defaults to 20 (list endpoints only) |
| `fields[<type>]` | string | Comma-separated list of fields to return. Use underscores for dashed attribute names (e.g., `module_source`). An empty value returns no fields. |

## List templates

`GET /dev-portal/organizations/:organization_name/templates`

| Parameter | Description |
| --- | --- |
| `:organization_name` | The name of the organization. |

Lists all application templates in the organization.

| Status | Response | Reason |
| --- | --- | --- |
| [200][] | [JSON API document][] (`type: "tdp-addon-definitions"`) | Successfully updated |
| [404][] | [JSON API error object][] | Add-on definition not found or user not authorized |

### Request Body

This PATCH endpoint requires a JSON object with the following properties as a request payload.

| Key path | Type | Default | Description |
| --- | --- | --- | --- |
| `data.type` | string | | Must be `"tdp-addon-definitions"`. |
| `data.id` | string | | The add-on definition ID. |
| `data.attributes` | object | | Object containing the attributes to update. |

### Sample Payload

```json
{
  "data": {
    "id": "addon-def-ghi789",
    "type": "tdp-addon-definitions",
    "attributes": {
      "module-id": "mod-pqr999"
    }
  }
}
```

### Sample Request

```shell
curl \
  --header "Authorization: Bearer $TOKEN" \
  --header "Content-Type: application/vnd.api+json" \
  --request PATCH \
  --data @payload.json \
  https://app.terraform.io/api/v2/dev-portal/organizations/my-organization/addon-definitions/postgres
```

### Sample Response

```json
{
  "data": {
    "id": "addon-def-ghi789",
    "type": "tdp-addon-definitions",
    "attributes": {
      "name": "postgres",
      "summary": "Managed PostgreSQL database",
      "description": "RDS Postgres with backups and IAM auth.",
      "module-source": "app.terraform.io/my-organization/postgres/aws",
      "module-id": "mod-pqr999",
      "variable-options": [
        {
          "variable-name": "engine_version",
          "variable-type": "string",
          "description": "Postgres major version",
          "user-editable": true,
          "options": ["15", "16"]
        }
      ],
      "readme-template": "# {{name}} database\n\nManaged PostgreSQL instance.",
      "created-at": "2026-09-20T10:00:00Z",
```

## Install an add-on

`POST /dev-portal/organizations/:organization_name/projects/:project_id/applications/:application_id/add-ons`

| Parameter | Description |
| --- | --- |
| `:organization_name` | The name of the organization. |
| `:project_id` | The project's external ID. |
| `:application_id` | The application ID or name. |

Installs an add-on into the application from an add-on definition.

| Status | Response | Reason |
| --- | --- | --- |
| [201][] | [JSON API document][] (`type: "tdp-addons"`) | Successfully created |
| [404][] | [JSON API error object][] | Application or add-on definition not found, or user not authorized |

### Request Body

This POST endpoint requires a JSON object with the following properties as a request payload.

| Key path | Type | Default | Description |
| --- | --- | --- | --- |
| `data.type` | string | | Must be `"tdp-addons"`. |
| `data.attributes.name` | string | | **Required.** Add-on name (1-50 characters). Also usable as `{add_on_id}` in other endpoints. |
| `data.attributes.readme` | string | | User-authored readme. |
| `data.attributes.tags` | array | | Tags for categorization. |
| `data.attributes.input-variables` | array | | Values for the definition's variables. Each item contains `variable-name`, `variable-type`, and `value`. Write-only; never returned. |
| `data.relationships.addon-definition.data` | object | | **Required.** Reference to the add-on definition. Contains `id` and `type` (`"tdp-addon-definitions"`). |

### Sample Payload

```json
{
  "data": {
    "type": "tdp-addons",
    "attributes": {
      "name": "checkout-db",
      "readme": "Primary datastore for checkout-api.",
      "tags": ["payments"],
      "input-variables": [
        {
          "variable-name": "engine_version",
          "variable-type": "string",
          "value": "16"
        }
      ]
    },
    "relationships": {
      "addon-definition": {
        "data": {
          "id": "addon-def-ghi789",
          "type": "tdp-addon-definitions"
        }
      }
    }
  }
}
```

