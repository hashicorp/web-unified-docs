# Connect AI clients to HCP Terraform with MCP server

The remote Terraform Model Context Protocol (MCP) server lets AI clients and AI
coding agents access your HCP Terraform organizations, your private registry,
and the public Terraform registry. HashiCorp hosts the server at
`https://mcp.terraform.io/mcp`, so you do not need to install or operate an MCP
server.

## Requirements

You must have the following to connect to the remote Terraform MCP server:

- An HCP Terraform account. During the beta, the remote server is available on all HCP Terraform plans, including Free.
- An HCP Terraform [user API token](/terraform/cloud-docs/users-teams-organizations/api-tokens#user-api-tokens) or [team API token](/terraform/cloud-docs/users-teams-organizations/api-tokens#team-api-tokens).
- An AI client that supports MCP servers over HTTP and lets you send a custom HTTP header with each request.

## Connect your AI client

Add `https://mcp.terraform.io/mcp` to your AI client's MCP configuration and send your API token in the `Authorization: Bearer` header. The server can only perform actions that your token has permission to perform.

Refer to [Connect to the remote Terraform MCP server](/terraform/mcp-server/deploy/remote-mcp) in the Terraform MCP server documentation for client configuration examples, available tools, and limitations.
