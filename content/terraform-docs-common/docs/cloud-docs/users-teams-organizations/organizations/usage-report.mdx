# Usage report

The Usage report provides visibility into your HCP Terraform resource consumption across projects, workspaces, and Stacks. You can view current billable managed resources, filter by tags, configure custom alerts, and review historical consumption patterns.

This topic describes how to use the Usage report to understand and manage your organization's resource consumption.

## Requirements

- Custom RUM alerts and historical insights require a pad billing plan. Refer to [Subscription plans](/terraform/cloud-docs/overview#subscription-plans) for more information.

## View resource consumption

The usage report provides a breakdown of billable managed resources across your organization. Follow these steps to view your organization's usage report.

1. Sign in to [HCP Terraform](https://app.terraform.io/) or Terraform Enterprise.
1. Navigate to your organization and click **Usage** in the sidebar.

The usage report page displays information about your organization's current plan, a summary of your usage data, an overview of your compliance tasks and policies, and a report of your billable managed resources.

## Billable managed resources

A managed resource is a Terraform resource that HCP Terraform manages for your organization. Refer to [Managed resources](/terraform/cloud-docs/overview#managed-resources) for more information.

Within the billable managed resource section, you can select and search for workspaces, projects, and Stacks. You can also filter the results by usage tags.

### Filter usage by tags

You can filter projects and workspaces by their assigned tags to understand resource consumption across different environments or cost centers.

1. In the **Billable managed resources** section, click **Filter by tags**.
1. Select one or more tags from the available options.
1. Click **Apply** to filter the view.

For example, you can filter by an `environment` tag to compare resource consumption between development and production environments. If one environment is consuming more resources than expected, drill into the relevant projects and workspaces to identify the source.

Refer to [Manage reserved tag keys](/terraform/cloud-docs/users-teams-organizations/organizations/manage-reserved-tags) for information about creating consistent tags across your organization.

## Configure managed usage alerts

<Note>

Managed usage alerts are available on paid billing plans.

</Note>

Managed usage alerts notify you when your organization's billable managed resources reach a specified threshold. This helps you monitor usage against your contracted RUM allocation without manually checking the Usage page.

1. In the **Billable managed resources** section, click **Manage usage alert**.
1. Set a threshold value for billable managed resources.
1. Click **Save changes**.

When your organization reaches the configured threshold, HCP Terraform sends notifications to the specified recipients. You can update or disable alerts at any time from the Usage page.

## Review historical usage

<Note>

Historical usage reports are available on paid billing plans.

</Note>

Historical usage reports show your organization's peak billable managed resources count at a monthly level, helping you understand consumption trends over time.

1. On the Usage page, click **Historical usage**.
1. Select a time range to view monthly peak consumption data.
