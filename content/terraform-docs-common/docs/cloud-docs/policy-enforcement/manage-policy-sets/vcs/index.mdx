# Use version control for policy sets

You can store your policies in a version control system (VCS) repository and connect that repository to HCP Terraform. When you push changes to the repository, HCP Terraform automatically uses the updated policies in your policy sets.

## Choose a policy engine

HCP Terraform supports three policy engines, each with different VCS repository structures and configuration requirements:

- **[Terraform policy](/terraform/cloud-docs/policy-enforcement/manage-policy-sets/vcs/terraform-policy)** - Native Terraform policy language with support for plugins and testing
- **[Sentinel](/terraform/cloud-docs/policy-enforcement/manage-policy-sets/vcs/sentinel)** - HashiCorp's policy-as-code framework with extensive import libraries
- **[OPA](/terraform/cloud-docs/policy-enforcement/manage-policy-sets/vcs/opa)** - Open Policy Agent using the Rego policy language

Each engine has specific requirements for repository structure, configuration files, and policy file naming conventions. Refer to the engine-specific documentation for detailed setup instructions.

## VCS workflow overview

The general workflow for using VCS-backed policy sets is:

1. **Create a repository**: Set up a VCS repository to store your policies
2. **Write policies**: Create policy files following your chosen engine's conventions
3. **Configure the policy set**: Create a configuration file that defines your policies and their enforcement levels
4. **Connect to HCP Terraform**: Link your VCS repository to HCP Terraform
5. **Apply to workspaces**: Configure which workspaces or projects the policy set applies to
6. **Update policies**: Push changes to your repository to automatically update the policy set

## Prerequisites

Before setting up VCS-backed policy sets, ensure you have:

- A connected VCS provider in HCP Terraform (refer to [Connecting VCS Providers](/terraform/cloud-docs/vcs))
- Appropriate permissions to create and manage policy sets (refer to [Organization Permissions](/terraform/cloud-docs/users-teams-organizations/permissions/organization))
- A VCS repository to store your policies
