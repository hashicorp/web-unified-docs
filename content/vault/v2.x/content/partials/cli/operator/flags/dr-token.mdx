**`-dr-token (string : "")`**

A [DR operation token](/vault/tutorials/enterprise/disaster-recovery#dr-operation-token-strategy)
for authenticating to a DR secondary cluster. Required when running
administrative commands (e.g., write operations) against a DR secondary
cluster, where standard Vault tokens are not accepted.

DR secondary clusters mirror the raft peer configuration of their DR primary.
Only use `-dr-token` when you need to manage raft nodes on the DR secondary
cluster directly (for example, to remove a failed node). Verify that any
changes you make are consistent with the peer set of the DR primary.

```shell-session
$ vault operator raft <subcommand> -dr-token <dr-operation-token>
```
