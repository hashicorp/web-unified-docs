**`-tpm-state-dir (string : ".")`**

Directory that holds the TPM attestation state, which is the wrapped key blobs
and the certificates. `attest` creates the directory, and any missing parent
directories, if it does not exist. `reattest`, `inspect` and `cleanup` read an
existing directory.

**Example**: `-tpm-state-dir /private`
