**`-tpm-state-dir (string : ".")`**

Directory that holds the TPM attestation state, which is the wrapped key blobs
and the certificates. `attest` and `reattest` create the directory if it does
not exist. `inspect` and `cleanup` require it to exist.

**Example**: `-tpm-state-dir /private`
