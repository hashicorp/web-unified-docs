**`-role-name (string : "")`**

The name of the role in the TPM auth method to attest against.

- `vault tpm attest`: Required.
- `vault tpm reattest`: Optional. If you omit this flag, the command uses the
  role from the existing `client.crt` in the state directory.

**Example**: `-role-name my-role`
