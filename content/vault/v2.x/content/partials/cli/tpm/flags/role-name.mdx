**`-role-name (string : "")`**

Name of the TPM auth method role to attest against. Required for `attest`. For
`reattest`, the flag is optional if the existing `client.crt` encodes the role
name as a subject alternative name (SAN). In that case, the command uses that
role.

**Example**: `-role-name my-role`
