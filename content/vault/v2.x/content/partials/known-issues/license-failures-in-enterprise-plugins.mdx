### Licensing Failures in Enterprise Plugins ((#license-failure-enterprise))

### Affected Plugins
Enterprise plugins (secrets-oracle-enterprise, secrets-openldap-enterprise, secrets-azure-enterprise, secrets-os) when run against
Vault 2.1

### Affected Vault Versions
2.1.x

### Affected Plugin Versions
- `secrets-oracle-enterprise` before 0.14.2+ent
- `secrets-openldap-enterprise` before 0.19.2+ent
- `secrets-azure-enterprise` before 0.28.3+ent
- `secrets-os` before 0.2.1+ent

### Issue
When an affected plugin is run against Vault 2.1.x+, it will fail with the message '* license wrapping failed: invalid module: "agentic-iam"'.
