### vault.raft_storage.log_store ((#vault-raft_storage-log_store))

Metric type | Value  | Description
----------- | ------ | -----------
gauge       | number | Identifies the Raft log store used by the reporting node.

The gauge has a value of `1` and includes the following labels:

- `peer_id` - Raft peer ID of the reporting node.
- `log_store` - Log store opened by the node: `raft_wal` or `raft_boltdb`.

Available in Vault 2.3 and later. The label reports `raft_boltdb` when an existing
`raft.db` file causes Vault to use BoltDB despite `log_store = "raft_wal"`.

Vault collects this metric on active and standby nodes that use integrated
storage.
