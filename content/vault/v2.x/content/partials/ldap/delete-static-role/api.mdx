Make a `DELETE` call to
[`/<mount>/static-role/<name>`](/vault/api-docs/secret/ldap#static-roles)
to delete the static role:

```shell-session
$ curl \
    --request DELETE \
    --header "X-Vault-Token: ${VAULT_TOKEN}" \
    ${VAULT_ADDR}/v1/<mount>/static-role/<name>
```
