Use `vault delete` with the
[`/<mount>/static-role/<name>`](/vault/api-docs/secret/ldap#static-roles)
path to delete the static role:

```shell-session
$ vault delete <mount>/static-role/<name>
```

For example:

<CodeBlockConfig hideClipboard>

```shell-session
$ vault delete devcreds/static-role/hashicorp
```

</CodeBlockConfig>
