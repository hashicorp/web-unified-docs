# Configure Microsoft Entra ID for SCIM with Vault

## Before you start

- **Get an Microsoft Azure subscription**.  Use an existing subscription or [Sign up for a free account](https://azure.microsoft.com/en-us/pricing/purchase-options/azure-account?icid=azurefreeaccount)

- **[Create a Microsoft Entra tenant](https://learn.microsoft.com/en-us/entra/identity-platform/quickstart-create-new-tenant)**. 

- **[Set up a Vault SCIM server](/vault/docs/iam/scim/setup)**. The Microsoft Entra ID SCIM application authenticates with a static bearer token, so create the SCIM client and its token before you configure provisioning.

- **Check your permissions**. On Azure, you must be able to:
   - create Microsoft Entra ID applications, groups and users. 

## Create Entra ID application, group and user

1. Use the Azure console to [create a new app registration](https://learn.microsoft.com/en-us/entra/identity-platform/quickstart-register-app).

1. [Create a group](https://learn.microsoft.com/en-us/entra/fundamentals/how-to-manage-groups).

1. [Create and assign user account to your application](https://learn.microsoft.com/en-us/entra/identity/enterprise-apps/add-application-portal-assign-users#assign-a-user-account-to-an-enterprise-application).  For OIDC authentication, the OIDC alias uses an email as a user name.  Also, ensure that you populate the `email` field for the user.

## Configure Microsoft Entra ID

After you enable SCIM on HCP, configure your identity provider to sync users and groups to HCP.

1. Sign into the Microsoft Entra admin center and select Enterprise applications from the Application side navigation.

Click All Applications and navigate to your custom application for HCP.

Click Provisioning, then select Get started or New configuration.

Configure the following fields in the Admin credentials section:

In the Tenant URL field, enter the value from the Base URL field you copied from HCP. Append the URL with ?aadOptscim062020. Refer to the Entra Id documentation to learn more about this Azure feature flag.
In the Secret token field, enter the SCIM token you copied from HCP.
To verify the configuration, select Test Connection.

If the conncetion is successful, click Create. Otherwise, refer to Troubleshoot SCIM provisioning for guidance.

Click Start provisioning.
