Section 1 – Vault SCIM Bootstrap (run once per cluster) 

Write the SCIM ACL Policy 

Grants the SCIM client token permission to call every SCIM v2 endpoint and manage its own client config. Without this policy, Entra's HTTP calls return 403. 

  

vault policy write scim-client-policy - <<'EOF' 

path "identity/scim/v2/Users" { capabilities = ["create","read","update","patch","delete","list"] } 

path "identity/scim/v2/Users/*" { capabilities = ["create","read","update","patch","delete","list"] } 

path "identity/scim/v2/Groups" { capabilities = ["create","read","update","patch","delete","list"] } 

path "identity/scim/v2/Groups/*" { capabilities = ["create","read","update","patch","delete","list"] } 

path "identity/scim/v2/ResourceTypes" { capabilities = ["read"] } 

path "identity/scim/v2/ResourceTypes/*" { capabilities = ["read"] } 

path "identity/scim/v2/Schemas" { capabilities = ["read"] } 

path "identity/scim/v2/Schemas/*" { capabilities = ["read"] } 

path "identity/scim/v2/ServiceProviderConfig" { capabilities = ["read"] } 

path "identity/scim/client" { capabilities = ["create","read","update","delete","list","patch"] } 

path "identity/scim/client/*" { capabilities = ["create","read","update","delete","list","patch"] } 

path "auth/token/create/scim-issuer-role" { capabilities = ["create","update","sudo"] } 

EOF 

 

Enable Userpass Auth & Capture the Accessor 

vault auth enable userpass 

 

USERPASS_ACCESSOR=$(vault auth list -format=json | jq -r '.["userpass/"].accessor') 

 

echo "Userpass accessor: $USERPASS_ACCESSOR" 

  

Create Entity  

CLIENT_ENTITY_ID=$(vault write -format=json identity/entity name="entra-scim-client" policies="scim-client-policy" | jq -r '.data.id') 

 

echo "Client entity ID: $CLIENT_ENTITY_ID" 

 

Create a Userpass Alias 

vault write identity/entity-alias name="entra-scim-user" canonical_id="$CLIENT_ENTITY_ID" mount_accessor="$USERPASS_ACCESSOR" 

  

Create the Userpass Credential (use a strong password in production) 

vault write auth/userpass/users/entra-scim-user password="changeme" policies="scim-client-policy" 

 

Create Entity Alias on Token Mount 

TOKEN_ACCESSOR=$(vault auth list -format=json | jq -r '."token/".accessor') 

 

echo "Token accessor: $TOKEN_ACCESSOR" 

 

vault write identity/entity-alias name="entra-scim-alias" canonical_id="$CLIENT_ENTITY_ID" mount_accessor="$TOKEN_ACCESSOR" 

 

Create Token Role for SCIM Token Issuance 

vault write auth/token/roles/scim-issuer-role allowed_entity_aliases="entra-scim-alias" orphan=true renewable=false 

 

Verify SCIM Endpoint 

SCIM_LOGIN_TOKEN=$(vault write -format=json auth/userpass/login/entra-scim-user password="changeme" | jq -r '.auth.client_token') 

 

curl -s -w "\nStatus: %{http_code}\n" -H "Authorization: Bearer $SCIM_LOGIN_TOKEN" "${VAULT_ADDR}/v1/admin/identity/scim/v2/ServiceProviderConfig" 

 

echo "Entra Tenant URL: ${VAULT_ADDR}/v1/admin/identity/scim/v2" 

 

Expected: Status 200. If not, stop and recheck policy and entity setup. 

 

Section 2: Test Scenarios Setup 

1-App SAML + SCIM 

One Entra Enterprise Application handles both SAML login and SCIM provisioning. Assigning a user grants both login access and provisioning. 

 

Create the Enterprise Application 

Azure Portal → Microsoft Entra ID → Enterprise applications → + New application → + Create your own application 

Name: "Vault EntraID SCIM Testing" (might already exist so use a different name) 

Select "Integrate any other application you don't find in the gallery" → Create 

From Properties, note the Object ID 

From Azure Portal → Microsoft Entra ID → Overview, note the Tenant ID 

 

Configure SAML SSO on the app 

Enterprise apps → Vault EntraID SCIM Testing → Single sign-on → SAML 

Basic SAML Configuration → Edit: 

Identifier (Entity ID): https://<vault-addr>:8200 

Reply URL (ACS URL): https://<vault-addr>:8200/v1/admin/auth/saml/callback 

Sign on URL: leave blank → Save 

Under SAML Signing Certificate, copy the App Federation Metadata URL 

Attributes & Claims: confirm the name claim emits user.userprincipalname (the UPN) — this must match the SCIM userName Entra sends 

 

Enable SAML auth in Vault and capture the accessor 

vault auth enable saml 

 

vault write auth/saml/config idp_metadata_url="<App Federation Metadata URL>" entity_id="https://<vault-addr>:8200" acs_urls="https://<vault-addr>:8200/v1/admin/auth/saml/callback" default_role="entra-saml-role" 

 

vault write auth/saml/role/entra-saml-role bound_subjects="*" bound_subjects_type="glob" user_attribute="http://schemas.xmlsoap.org/ws/2005/05/identity/claims/name" token_policies="default" token_ttl="1h" 

 

SSO_ACCESSOR=$(vault auth list -format=json | jq -r '."saml/".accessor') 

 

echo "SAML accessor: $SSO_ACCESSOR" 

 

Register SCIM Client with SAML Accessor 

vault write identity/scim/client/entra-iga-client access_grant_principal="$CLIENT_ENTITY_ID" alias_mount_accessor="$SSO_ACCESSOR" allow_user_adoption=true allow_group_adoption=true max_active_tokens=5 max_token_ttl="720h" default_schema_version="2.1" 

 

vault read identity/scim/client/entra-iga-client 

 

export SCIM_CLIENT_NAME="entra-iga-client" 

 

Confirm alias_mount_accessor equals $SSO_ACCESSOR -- if blank, stop. 

 

Issue SCIM Token 

SCIM_TOKEN=$(curl -s -X POST -H "X-Vault-Token: $VAULT_ADMIN_TOKEN" -H "X-Vault-Namespace: admin" -H "Content-Type: application/json" "$VAULT_ADDR/v1/auth/token/create/scim-issuer-role" -d '{"type":"scim","ttl":"720h","policies":["scim-client-policy"],"renewable":false,"no_default_policy":true,"entity_alias":"entra-scim-alias"}' | jq -r '.auth.client_token') 

 

export SCIM_TOKEN 

 

echo $SCIM_TOKEN 

 

Verify Token 

echo "$SCIM_TOKEN" | grep -q "^scm\." && echo "OK: scm. prefix correct" || echo "ERROR: wrong prefix" 

 

vault token lookup -format=json $SCIM_TOKEN | jq '{type:.data.type, orphan:.data.orphan, renewable:.data.renewable, entity_id:.data.entity_id}' 

 

entity_id must be non-empty. If it's empty, stop and recheck the entity alias on the token mount. 

 

Verify Token Reaches Vault 

curl -s -w "\nStatus: %{http_code}\n" -H "Authorization: Bearer $SCIM_TOKEN" "${VAULT_ADDR}/v1/admin/identity/scim/v2/ServiceProviderConfig" 

 

Configure Provisioning in Entra
