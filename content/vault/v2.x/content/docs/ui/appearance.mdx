# Change the Vault GUI appearance

@include 'alerts/enterprise-only.mdx'

Use the **Appearance** section of the **Preferences** page to choose a light
theme, a dark theme, or a theme that follows your operating system. Vault stores
your choice in your browser, so it does not follow you to other browsers or
devices.

## Before you start

- **Log in to the Vault GUI**. The **Preferences** page is available from the
  user menu after you log in. You do not need any policy capabilities to open it
  or change the theme.

- **Optional: Check your operating system theme**. If you plan to select
  **System**, set your operating system to the light or dark appearance you want
  Vault to follow.

## Step 1: Open Preferences

1. Log in to the Vault GUI.

1. Select the **User menu** icon.

1. Select **Preferences**.

   The **Preferences** page opens. The **Appearance** section is below the
   **Your role** and **Data & privacy** sections. The **Data & privacy** section
   does not appear on HCP Vault Dedicated clusters.

## Step 2: Choose a theme

In the **Appearance** section, select one of the following theme cards:

| Card | Description shown in the GUI | Behavior |
| ---- | ---------------------------- | -------- |
| **Light** | Vault will be displayed in light mode. | Always uses the light theme. |
| **Dark** (beta) | Vault will be displayed in dark mode. | Always uses the dark theme. The GUI labels this card **Beta**. |
| **System** | Vault will follow your operating system theme. | Uses the dark theme when your operating system is set to dark, and the light theme otherwise. |

The theme changes as soon as you select a card. You do not need to save or
reload the page.

When you select **System** and then change your operating system between light
and dark, the Vault GUI updates immediately without a reload. When you select
**Light** or **Dark**, changes to your operating system theme have no effect.

## Step 3: Verify that the theme persists

1. Reload the browser page.

   The GUI keeps your theme, and the card you selected is still selected in the
   **Appearance** section.

1. Optional: Open the Vault GUI in a second tab of the same browser.

   The second tab uses the same theme. When you change the theme in one tab,
   other open Vault GUI tabs in the same browser update to match.

## Persistence and limitations

The Vault GUI stores the theme choice in the browser's local storage under the
key `vault:prefs:theme`. The stored value is `"light"`, `"dark"`, or
`"system"`. The following rules apply:

- **Default**. When the browser has no stored value, the GUI uses **System**.
  Clearing your browser's site data for the Vault address returns the theme to
  **System**.
- **Per browser**. Vault does not save the theme on the Vault server or with
  your token, entity, or identity. The theme does not follow you to another
  browser, another browser profile, or another device.
- **Per Vault address**. Browsers keep local storage separately for each origin,
  so each Vault address (scheme, host, and port) has its own theme setting.
- **Storage unavailable**. If the browser blocks local storage, the theme
  changes for the current page but does not persist after you reload.
