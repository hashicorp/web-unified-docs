# Feature spotlight widget in the Vault GUI

@include 'alerts/enterprise-only.mdx'

The feature spotlight widget on the Vault GUI dashboard highlights Vault
features in a set of cards. Each card has a title, a short description, and a
link to learn more about the feature.

## Where the widget appears

The widget appears at the top of the right-hand column of the dashboard, above
the **Quick actions** widget. Vault Enterprise shows the widget. The Vault
Community Edition dashboard does not include it.

## How the cards work

The widget contains a fixed list of cards. Each card can include the following
elements:

- **Title**: The name of the feature.
- **Description**: A short summary of what the feature does.
- **Image**: An optional illustration. In dark mode, the widget shows the
  dark-mode version of the image when the card provides one.
- **Link**: A call-to-action link at the bottom of the card. The link opens one
  of the following destinations:
  - A page on the Vault documentation site. The page opens as an external link.
  - A page in the Vault GUI, for example the **Preferences** page.

  The link text is **Learn more** unless the card sets its own text, such as
  **Try it out**.

Vault picks the card that the widget shows first at random each time the
dashboard loads. As a result, you may see a different card each time you open
the dashboard.

## Browse the cards

When the widget has more than one card, it shows a page label, such as `2/4`,
and the **Back** and **Next** buttons.

1. Click **Next** to show the next card in the list.
1. Click **Back** to show the previous card in the list.

The cards always appear in the same order, regardless of which card the widget
shows first. The buttons wrap around: **Next** on the last card shows the first
card, and **Back** on the first card shows the last card.

If the widget has only one card, Vault hides the page label and the buttons.

## Telemetry events

If an operator enables GUI telemetry and you consent to share usage metrics,
the widget emits an event when you click **Back**, **Next**, or the card link.
Refer to [GUI telemetry events](/vault/docs/internals/telemetry/metrics/ui-telemetry-events)
for the event properties.
