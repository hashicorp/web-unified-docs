# Use Hideez for OIDC authentication

[Hideez Workforce Identity](https://hideez.com/pages/hideez-authentication-service)
is a passwordless identity provider that supports OpenID Connect. The following
steps configure Vault's [OIDC auth method](/vault/docs/auth/jwt) to sign users
in with Hideez.

## Create the Hideez application

1. In the Hideez admin console, go to **Integrations** > **OIDC** and click
   **Create App Integration**.
1. Select **Web Application** and click **Next**.
1. Enter a **Name**, such as `Vault`. Keep **Authorization Code** selected under
   **Grant Types**.
1. In **Redirect Uri**, enter the callback URL of your Vault UI, such as
   `https://vault.example.com:8200/ui/vault/auth/oidc/oidc/callback`.
1. Leave **Proof Key for Code Exchange (PKCE)** enabled and click **Create**.
1. Copy the **Client Id** and **Client Secret**. Hideez shows the secret only
   right after you create the application. You can generate a new one later with
   **Regenerate**.
1. Open the **Parameters** tab and copy the **Issuer**.
1. Hideez only lets users sign in to applications that are assigned to them. Go
   to **User Management** > **Groups**, create a group, add your users to it,
   and assign the application on the **Applications** tab of the group.

## Configure Vault

Enable the OIDC auth method and set `oidc_discovery_url` to the **Issuer** value
exactly as Hideez shows it, including the trailing slash.

```shell-session
$ vault auth enable oidc

$ vault write auth/oidc/config \
    oidc_discovery_url="your_issuer_url" \
    oidc_client_id="your_client_id" \
    oidc_client_secret="your_client_secret" \
    default_role="default"
```

Create a role that matches the redirect URI you entered in Hideez.

```shell-session
$ vault write auth/oidc/role/default \
    allowed_redirect_uris="https://vault.example.com:8200/ui/vault/auth/oidc/oidc/callback" \
    user_claim="sub" \
    oidc_scopes="openid,email,profile" \
    policies="default"
```

Select the **OIDC** method on the Vault sign-in page and click **Sign in with
OIDC Provider** to sign in with Hideez.
