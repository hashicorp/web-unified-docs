# `tpm enroll`

@include 'alerts/enterprise-only.mdx'

Register a TPM in the Vault identity store.

<CodeBlockConfig hideClipboard>

```shell-session
$ vault tpm enroll [flags]

$ vault tpm enroll [-help | -h]
```

</CodeBlockConfig>

## Description

`vault tpm enroll` hashes the endorsement key (EK) public key of a TPM to derive
the stable TPM ID (`sha256-<hex>`) and registers it in the Vault identity store
under `identity/tpm`. By default, the command reads the EK public key from the
local TPM. To enroll a TPM on another host, use `-ekpem` to provide its EK
public key.

Use the TPM ID to authorize the TPM in a
[TPM auth method role](/vault/api-docs/auth/tpm). By default, Vault also uses
the TPM ID as the identity alias name. To change this, refer to
[`alias_mode`](/vault/api-docs/auth/tpm#configure).

<Tip title="Related API endpoints">

  CreateTPM - [`POST:/identity/tpm`](/vault/api-docs/secret/identity/tpm#create-a-tpm)

</Tip>

## Examples

Enroll the local TPM and name the record `my-tpm`:

```shell-session
$ vault tpm enroll -name=my-tpm -tpm-device-path=/dev/tpm0
```

Enroll the local TPM with metadata:

```shell-session
$ vault tpm enroll -name=my-tpm -metadata=location=datacenter-east
```

Print only the TPM ID:

```shell-session
$ vault tpm enroll -field=id -name=my-tpm -tpm-device-path=/dev/tpmrm0
```
