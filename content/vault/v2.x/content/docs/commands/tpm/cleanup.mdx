# `tpm cleanup`

@include 'alerts/enterprise-only.mdx'

Delete the TPM attestation files from the state directory.

<CodeBlockConfig hideClipboard>

```shell-session
$ vault tpm cleanup [flags]

$ vault tpm cleanup [-help | -h]
```

</CodeBlockConfig>

## Description

`vault tpm cleanup` deletes the certificates and key references that
[`vault tpm attest`](/vault/docs/commands/tpm/attest) wrote to the state
directory. The command leaves the directory in place and does not touch other
files in it. The state directory must exist. Refer to
[Attestation state directory](/vault/docs/auth/tpm#attestation-state-directory)
for the list of files.

## Examples

Delete the attestation files from `/private`:

```shell-session
$ vault tpm cleanup -tpm-state-dir=/private
Removed client-key.json
Removed ak.blob
Removed app.blob
Removed ca_chain.pem
Removed client.crt
Cleanup complete. 5 file(s) removed from /private
```
