# `tpm inspect`

@include 'alerts/enterprise-only.mdx'

Report the certificate and attestation status stored in the state directory.

<CodeBlockConfig hideClipboard>

```shell-session
$ vault tpm inspect [flags]

$ vault tpm inspect [-help | -h]
```

</CodeBlockConfig>

## Description

`vault tpm inspect` reads the files that
[`vault tpm attest`](/vault/docs/commands/tpm/attest) saved in the state
directory and reports the certificate and attestation status. The command works
locally and does not contact Vault. The state directory must exist.

</Tip>
