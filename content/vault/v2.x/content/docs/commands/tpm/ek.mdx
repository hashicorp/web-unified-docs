# `tpm ek`

@include 'alerts/enterprise-only.mdx'

Print the endorsement key public key and TPM ID of the local TPM.

<CodeBlockConfig hideClipboard>

```shell-session
$ vault tpm ek [flags]

$ vault tpm ek [-help | -h]
```

</CodeBlockConfig>

## Description

`vault tpm ek` reads the endorsement key (EK) public key from the local TPM and
prints it as PEM along with the TPM ID (`sha256-<hex>`). The command does not
register the TPM with Vault. To register a TPM, use
[`vault tpm enroll`](/vault/docs/commands/tpm/enroll).
