# `vault tpm`

@include 'alerts/enterprise-only.mdx'

Interact with a local Trusted Platform Module (TPM) 2.0 device to enroll machine
identity and attest hardware for certificate-bound authentication to Vault.

<CodeBlockConfig hideClipboard>

```shell-session
$ vault tpm <subcommand> [flags]

$ vault tpm [-help | -h]
```

</CodeBlockConfig>

## Description

`vault tpm` performs no work on its own. Use one of its subcommands:

- [`enroll`](/vault/docs/commands/tpm/enroll) - Register a TPM in the Vault
  identity store.
- [`ek`](/vault/docs/commands/tpm/ek) - Print the endorsement key public key and
  TPM ID of the local TPM.
- [`attest`](/vault/docs/commands/tpm/attest) - Get a TPM-bound client
  certificate and save it with its key references.
- [`reattest`](/vault/docs/commands/tpm/reattest) - Renew the saved client
  certificate.
- [`inspect`](/vault/docs/commands/tpm/inspect) - Report the certificate and
  attestation status from the state directory.
- [`cleanup`](/vault/docs/commands/tpm/cleanup) - Delete the saved certificate
  and key files.

For concepts, refer to [TPM auth method](/vault/docs/auth/tpm). For setup steps,
refer to [Set up the TPM auth method](/vault/docs/auth/tpm/tpm).

## Examples

Enroll the local TPM:

```shell-session
$ vault tpm enroll -name=my-tpm -tpm-device-path=/dev/tpm0
```

Attest the local TPM against the `my-role` role:

```shell-session
$ vault tpm attest -role-name=my-role -tpm-state-dir=/private
```

Delete the attestation files:

```shell-session
$ vault tpm cleanup -tpm-state-dir=/private
```
