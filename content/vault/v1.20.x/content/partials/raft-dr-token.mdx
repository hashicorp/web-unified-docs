<Note title="DR secondary clusters">

  To run this command on a **DR secondary** cluster, use the `-dr-token` flag
  with a valid DR operation token. DR secondary clusters mirror their DR
  primaries, so any changes should first be made on the primary cluster.

  ```shell-session
  $ vault operator raft <subcommand> -dr-token <dr-operation-token>
  ```

  For more information, see the
  [DR operation token documentation](/vault/docs/enterprise/replication#dr-operation-token).

</Note>
