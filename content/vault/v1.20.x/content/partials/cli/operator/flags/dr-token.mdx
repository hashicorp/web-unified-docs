**`-dr-token (string : "")`**

A [DR operation token](/vault/tutorials/enterprise/disaster-recovery#dr-operation-token-strategy)
for authenticating to a DR secondary cluster. Required when running this command
against a DR secondary cluster, where standard Vault tokens are not accepted.

DR secondary clusters mirror the raft peer configuration of their DR primary.
Only use this flag when you need to manage the DR secondary cluster's raft nodes
directly (for example, to remove a failed node). Verify that any changes you
make are consistent with the DR primary's peer set.

```shell-session
$ vault operator raft <subcommand> -dr-token <dr-operation-token>
```
