#### Issue

When initialization of a database connection fails, Vault may not clean up the
database plugin subprocesses and associated resources. Repeated failures can
increase resource usage over time.

The issue affects all of the following Oracle Enterprise database plugin versions:

- `vault-plugin-database-oracle_0.14.1+ent`
- `vault-plugin-database-oracle_0.14.0+ent`
- `vault-plugin-database-oracle_0.13.0+ent`
- `vault-plugin-database-oracle_0.12.3+ent`
- `vault-plugin-database-oracle_0.11.0+ent`

The issue is also reported for Vault Enterprise 1.18.5+, 1.17.12+, and 1.16.16+.

#### Recommendation

Monitor Vault's memory usage and open file descriptors if you use external
Enterprise database plugins. Contact HashiCorp Support if resource usage grows
over time.
