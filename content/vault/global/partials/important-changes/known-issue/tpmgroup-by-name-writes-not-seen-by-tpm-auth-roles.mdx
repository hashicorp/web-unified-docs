### Vault Agent reissues PKI external CA certificates on every re-authentication ((#agent-pki-external-ca-reissue-on-reauth)) <EnterpriseAlert inline="true" />

<!-- BEGIN: Vault:=v2.x -->

| Change      | Status   | Vault edition | Affected version | Fixed version
| ----------- | -------- | ------------- | ---------------- | -------------
| Known issue | Open     | Enterprise    | 2.2.0+ent        | None

<!-- END: Vault:=v2.x -->

#### Issue

If you update the membership of a TPMGroup or delete the TPMGroup is deleted
using the `identity/tpmgroup/name/:name` endpoint, auth and TPM roles that
reference the group will not see the change on the primary active node.
Downstream nodes will see the change, so a leadership change or seal/unseal
eventually makes the change visible to auth/tpm roles.

#### Workaround

Lookup the ID of the TPMGroup to modify, then use the `identity/tpmgroup/id/:id` endpoint
to make the change.
