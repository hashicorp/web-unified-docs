### Vault Agent reissues PKI external CA certificates on every re-authentication ((#agent-pki-external-ca-reissue-on-reauth)) <EnterpriseAlert inline="true" />

<!-- BEGIN: Vault:=v2.x -->

| Change      | Status   | Vault edition | Affected version | Fixed version
| ----------- | -------- | ------------- | ---------------- | -------------
| Known issue | Open     | Enterprise    | 2.2.0+ent        | None

<!-- END: Vault:=v2.x -->

#### Issue

If an update is made to a TPMGroup's membership or a TPMGroup is deleted, and the
change is done using the endpoint `identity/tpmgroup/name/:name`, the change won't be
seen by any auth/tpm roles that reference the group. This only applies to the primary
active node: downstream nodes will see the change. A leadership change or seal/unseal
will make the change visible to auth/tpm roles.

#### Workaround

Lookup the ID of the TPMGroup to modify, then use the `identity/tpmgroup/id/:id` endpoint
to make the change.
