### TPMGroup membership/deletion not reflected in auth roles on primary node ((#tpmgroup-by-name-writes-not-seen-by-tpm-auth-roles)) <EnterpriseAlert inline="true" />

<!-- BEGIN: Vault:=v2.x -->

| Change      | Status   | Vault edition | Affected version | Fixed version
| ----------- | -------- | ------------- | ---------------- | -------------
| Known issue | Closed   | Enterprise    | 2.2.0+ent        | 2.2.1+ent

<!-- END: Vault:=v2.x -->

#### Issue

If you update the membership of a TPMGroup or delete a TPMGroup
using the `identity/tpmgroup/name/:name` endpoint, auth and TPM roles that
reference the group will not see the change on the primary active node.
Downstream nodes will see the change, so a leadership change or seal/unseal
eventually makes the change visible to auth/tpm roles.

#### Workaround

On Vault 2.2.0+ent, look up the ID of the TPMGroup to modify, then use the
`identity/tpmgroup/id/:id` endpoint to make the change.
