#### Issue

Microsoft Graph errors can prevent Vault from permanently deleting an Azure
application. If deleting the active application returns a 404,
Vault continues to the permanent purge request. Other errors during deletion, or
an error from the purge request, can still prevent cleanup from completing. If
cleanup does not succeed, Azure resources may remain.

#### Recommendation

Check your Vault logs and verify the status of your application in Azure before treating
cleanup as complete. If cleanup remains unsuccessful, ask an Azure administrator
to investigate and remove any remaining resources.
