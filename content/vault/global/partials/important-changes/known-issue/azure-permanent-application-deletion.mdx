#### Issue

When Vault permanently deletes an Azure application, Microsoft Graph errors can
cause a cleanup attempt to fail. If deleting the active application fails, Vault
may not proceed to the permanent purge request. Vault retries failed cleanup for
issued credentials. If setup fails before Vault issues a credential, Vault uses
a separate rollback process. If cleanup does not succeed, Azure resources may
remain.

#### Recommendation

Check Vault logs and verify the application's status in Azure before treating
cleanup as complete. If cleanup remains unsuccessful after Vault retries, ask an
Azure administrator to investigate and remove any remaining resources.
