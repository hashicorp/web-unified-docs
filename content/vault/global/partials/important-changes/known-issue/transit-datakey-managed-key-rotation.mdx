### Transit datakey and datakeys endpoints fail for keys rotated to a managed key ((#transit-datakey-managed-key-rotation)) <EnterpriseAlert inline="true" />

<!-- BEGIN: Vault:=v2.x -->

| Change      | Status   | Vault edition | Affected version | Fixed version
| ----------- | -------- | ------------- | ---------------- | -------------
| Known issue | Closed   | Enterprise    | 2.2.0+ent        | 2.2.1+ent

<!-- END: Vault:=v2.x -->

#### Issue

The Transit [`datakey`](/vault/api-docs/secret/transit#generate-data-key) and
[`datakeys`](/vault/api-docs/secret/transit#generate-multiple-data-keys)
endpoints return an error if the provided key version is a `managed_key` type
that Vault created using the
[Rotate with Algorithm Change](/vault/api-docs/secret/transit#rotate-with-algorithm-change)
endpoint from a key whose original algorithm was not `managed_key`.

#### Workaround

Create a new Transit key configured with the desired managed key.
