### Azure static credentials display incorrect last rotation time when seamless rotation is enabled ((#azure-seamless-incorrect-last-rotation)) <EnterpriseAlert inline="true" />

<!-- BEGIN: Vault:=v2.x -->

| Change      | Status | Vault edition | Affected version | Fixed version
| ----------- | ------ | ------------- | ---------------- | -------------
| Known issue | Open   | Enterprise    | 2.2.0+ent        | None

<!-- END: Vault:=v2.x -->

#### Issue

The [static credential](/vault/api-docs/secret/azure#get-static-credentials) endpoint returns an incorrect value for the `last_vault_rotation` field when [seamless rotation](/vault/docs/secrets/azure#seamless-rotation) has been enabled.

#### Workaround

Manually calculate the `last_vault_rotation` by subtracting the `rotation_period` configured the static role from the `expiration` date returned when reading the credentials.
