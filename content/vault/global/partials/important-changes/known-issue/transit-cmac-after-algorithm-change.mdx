### Transit CMAC endpoint fails for keys rotated to a CMAC key ((#transit-cmac-after-algorithm-change)) <EnterpriseAlert inline="true" />

<!-- BEGIN: Vault:=v2.x -->

| Change      | Status   | Vault edition | Affected version | Fixed version
| ----------- | -------- | ------------- | ---------------- | -------------
| Known issue | Closed   | Enterprise    | 2.2.0+ent        | 2.2.1+ent

<!-- END: Vault:=v2.x -->

#### Issue

The Transit [`cmac`](/vault/api-docs/secret/transit#generate-cmac)
endpoint returns an error if the provided key version is a `aes128-cmac`, `aes192-cmac`,
or `aes256-cmac` type that Vault created using the [Rotate with Algorithm Change](/vault/api-docs/secret/transit#rotate-with-algorithm-change)
endpoint from a key whose original algorithm does not support CMAC.

#### Workaround

Create a new Transit key to use for CMAC.
