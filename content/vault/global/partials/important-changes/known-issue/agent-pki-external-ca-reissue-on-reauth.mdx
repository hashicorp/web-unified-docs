### Vault Agent reissues PKI external CA certificates on every re-authentication ((#agent-pki-external-ca-reissue-on-reauth)) <EnterpriseAlert inline="true" />

<!-- BEGIN: Vault:=v2.x -->

| Change      | Status   | Vault edition | Affected version | Fixed version
| ----------- | -------- | ------------- | ---------------- | -------------
| Known issue | Open     | Enterprise    | 2.2.0+ent        | None

<!-- END: Vault:=v2.x -->

#### Issue

When you configure Vault Agent with a
[`pki_external_ca`](/vault/docs/agent-and-proxy/agent/pki-external-ca) stanza,
Vault Agent requests a new certificate every time auto-auth re-authenticates
and receives a new token, even if the current certificate is valid. Vault Agent
ignores the `percent_renew_before_expiry` setting and the scheduled renewal time
for the certificate.

On each re-authentication, Vault Agent logs `Manual renewal triggered`, creates
a new ACME order, generates a new private key, and writes the new certificate
and key to the configured destination. Token renewals do not trigger
reissuance.

#### Workaround

None.
