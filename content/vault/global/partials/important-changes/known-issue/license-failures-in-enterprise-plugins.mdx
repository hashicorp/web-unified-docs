### Licensing failures in Enterprise plugins ((#license-failure-enterprise))

The following plugins fail with the message
`'* license wrapping failed: invalid module: "agentic-iam"'` when paired with a
Vault license with the `agentic-iam` feature enabled.

Affected plugin               | Plugin version    | Vault version
----------------------------- | ----------------- | -------------
`secrets-oracle-enterprise`   | before 0.14.2+ent | 2.1.x+
`secrets-openldap-enterprise` | before 0.19.2+ent | 2.1.x+
`secrets-azure-enterprise`    | before 0.28.3+ent | 2.1.x+
`secrets-os`                  | before 0.2.1+ent  | 2.1.x+
