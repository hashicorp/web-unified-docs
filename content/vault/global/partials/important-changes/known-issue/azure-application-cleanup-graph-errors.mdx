#### Issue

Microsoft Graph errors can prevent Vault from permanently deleting an Azure
application. Vault retries failed cleanup, but if the errors continue, the
application may remain in Azure.

#### Recommendation

Check Vault logs and verify the application's status in Azure. If cleanup
continues to fail after Vault retries, ask an Azure administrator to investigate
and remove any remaining resources.
