# Word List

Wondering if we capitalize a word? Or what a term means? Here's a list of some of the most common.

If a software term isn't listed, or the company's GitHub repo are good resources to confirm spelling and capitalization.

**Tip:** Avoid capitalizing these terms mid-sentence to prevent over-emphasizing buzzwords. One key exception: DevOps is always capitalized.

## Industry Definitions, Technical Software Terms, and Other Words

- **agile development** avoid saying "Agile" since there's no definitive definition so it doesn't merit having proper noun status
- **AI and artificial intelligence** either is OK, interchangeable

- **Ansible**
- **autoscaling**

### X-Z

- **10x or 100x** if abbreviation is needed you can use this but we prefer you say something like "10 times faster." Don't use x10 or x100
- **zero trust** (zero trust networking, zero trust architecture, and zero trust security) Zero trust is a security perspective where you don't assume the security methods at your IT environment's perimeter will stop all attackers, so you treat all traffic and individuals outside and inside your environment as potential attackers and always require credentials (which could be managed via Vault) and authenticated service-to-service communication (which could be managed via Consul service mesh).
