## Authentication

### Via the CLI

The default path is `/name`. If this auth method was enabled at a different path,
specify `-path=/my-path` in the CLI.

```shell-session
$ vault login -method=name credential="<credential>"
```

`<Describe any environment variable alternative.>`

### Via the API

The default endpoint is `auth/name/login`. If this auth method was enabled at a
different path, use that value instead of `name`.

```shell-session
$ curl \
    --request POST \
    --data '{"credential": "<credential>"}' \
    http://127.0.0.1:8200/v1/auth/name/login
```

The response contains a token at `auth.client_token`:

```json
{
  "auth": {
    "renewable": true,
    "lease_duration": 2764800,
    "policies": ["default", "dev-policy"],
    "client_token": "<token>"
  }
}
```
