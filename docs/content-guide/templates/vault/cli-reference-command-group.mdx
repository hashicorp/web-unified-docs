# `vault command`

One sentence describing what the command group does.

<CodeBlockConfig hideClipboard>

```shell-session
$ vault command -config <config_file>

$ vault command [-help | -h]
```

</CodeBlockConfig>

## Description

Full description of the command group. Where the group command performs no work
on its own, say so and point at the subcommands.

  **None**

</Tip>
