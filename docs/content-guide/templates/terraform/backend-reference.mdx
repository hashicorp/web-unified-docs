# `backend_name` backend

Name the backend and the service it stores state in. Say whether it supports
state locking, in one sentence, because that is the first thing a reader checks.

## Example Configuration

Show a complete, working `backend` block before any reference material:

```hcl

  backend "backend_name" {
    setting = "value"
  }
}
```

## Data Source Configuration

Show how to read this backend's state from the `terraform_remote_state` data
source, which is a different configuration shape from the backend block:

```hcl
data "terraform_remote_state" "example" {
  backend = "backend_name"

  config = {
    setting = "value"
  }
}
```
