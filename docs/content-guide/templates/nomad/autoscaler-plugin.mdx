# `plugin_name` plugin

Name the plugin, say which of the Autoscaler's plugin categories it belongs to —
target, strategy, APM — and what it does. One or two sentences.

## Agent Configuration Options

Options set in the Nomad Autoscaler agent's configuration file, which configure
the plugin itself:

```hcl
target "plugin_name" {
  driver = "plugin_name"
  config = {
    option_name = "value"
  }
}
```

- `option_name` `(string: "")` - `<What it configures.>` `<Whether it is
  required.>`

## Policy Configuration Options

Options set in a scaling policy, which configure how the plugin behaves for that
policy:

```hcl
check "check_name" {
  source = "..."
  query  = "..."

  target "plugin_name" {
    option_name = "value"
  }
}
```

- `option_name` `(string: <required>)` - `<What it configures.>` `<Accepted
  values and default.>`
