# `driver_name` task driver

Name the driver and what it runs. One or two sentences. Link the
[task driver overview](/nomad/docs/deploy/task-driver) and any external runtime
the driver depends on.

## Client Attributes

Fingerprinted attributes the driver publishes, which job authors can use in
constraints:

- `driver.driver_name` - Whether the driver is enabled on the node.
- `driver.driver_name.version` - The runtime version detected on the node.
