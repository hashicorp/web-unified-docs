## Complete configuration

The following {construct} includes all supported {elements}:

```hcl
ElementA = <default or description of value>
ElementB = {
  ElementC = <default or description of value>
  ElementD = {
    ElementE = <default or description of value>
    ElementF = <default or description of value>
      ElementG = ["<description of value>"]
  ElementH = <default or description of value>
  ElementI = <default or description of value>
  }
```
